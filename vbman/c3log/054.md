# Fix 054: Variant 表达式 compound literal 修复 + 类成员 Variant 赋值包装

## 日期
2026-07-23

## 错误概览
- 修复前: 1207 个总错误, C2440 509 个
- 修复后: 1177 个总错误, C2440 460 个
- 净减少: -30 个总错误, -49 个 C2440

## 根因分析

### 根因1: compound literal `.bstrVal=` 接收 Variant 表达式 (45个 C2440)

`cgen_expr.cpp` 参数包装代码中, 当 `inferExprType()` 返回 Variant/unknown 时,
`default` 分支生成 `(&(vb6_VARIANT){.vt=VT_BSTR, .bstrVal=EXPR})`.

当 EXPR 是 `vb6_VARIANT` 类型 (如 `vb6_VariantArrayGet(&vErr, 1)`) 时,
无法将 `vb6_VARIANT` 赋值给 `.bstrVal` (BSTR 字段), 产生 C2440.

### 根因2: 类成员 Variant 字段赋值未包装 (46个 C2440)

`cgen_stmt.cpp` Let/Assignment 语句中, `targetIsVariant` 只检查 `knownVariantVars_` (局部变量),
不检查 `classVariantMembers_` (类成员 Variant 字段).

当赋值 `me->m_P1 = vb6_PA_GetLong(P, i)` 时, `m_P1` 是 Variant 字段但未被检测到,
导致 `int32_t` 值直接赋值给 `vb6_VARIANT` 字段, 产生 C2440.

## 修复方案

### 修改1: compound literal default 分支 — Variant 表达式提取 BSTR
**文件**: `src/backend/cgen_expr.cpp` (line ~3306)

在 `default` 分支中, 使用 `cExprIsVariant(argVal)` 检测 C 级 Variant 表达式:
- 如果是 Variant → `(&(vb6_VARIANT){.vt=VT_BSTR, .bstrVal=vb6_VariantToString(EXPR)})`
- 否则保持原样 → `(&(vb6_VARIANT){.vt=VT_BSTR, .bstrVal=EXPR})`

注意: C 复合字面量 `{EXPR}` 初始化第一个字段而非整个结构体, 不能用 `(&(vb6_VARIANT){EXPR})` 复制 Variant.

### 修改2: 类成员 Variant 字段赋值检测
**文件**: `src/backend/cgen_stmt.cpp` (line ~776)

在 `targetIsVariant` 检测中, 添加 `classVariantMembers_.count(lower)` 检查.
当目标是 `me->m_Px` 等类成员 Variant 字段时, 自动用 `wrapVariantValue` 包装赋值.
