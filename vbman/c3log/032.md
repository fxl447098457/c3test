# Fix 032 — asCallCallee_ 状态泄漏 + PropertyDecl currentProc_ 符号查找错误

## 错误现象

### 问题 A：C2065 Property Get 自引用错误（11 例）

在 `cTlsReMaster.cls` Property Get `LocalHostName` 中：

```vb6
pvSocket.GetLocalHost LocalHostName, vbNullString
```

`LocalHostName` 是当前 Property Get 的返回值隐式变量（应 emit `&vb6_ret_LocalHostName`），但 C3 错误地生成 `vb6_cTlsReMaster_LocalHostName`（过程名）→ 未定义符号 C2065。

### 问题 B：C2198 137 例 "parameter not enough"

Property Let/Set 过程体内引用赋值 RHS 参数（如 `Property Let SockOpt(..., ByVal Value As Long)` 中的 `Value`）时，被误识别为跨模块 PropertyGet 调用，导致实参列表缺失，ws_setsockopt 的 ByRef 参数无法匹配。

## 根本原因

### Bug A: asCallCallee_ 状态泄漏到 args 发射区

`visit(IndexOrCallExpr&)` 在 cgen_expr.cpp:2159-2162 设置 `asCallCallee_ = true` 用于 callee 发射，恢复为 `savedAsCallCallee`。但外层 `visit(CallStmt&)` 在 cgen_stmt.cpp:2159-2162 也设置了 `asCallCallee_ = true`，所以 IndexOrCallExpr 的 `savedAsCallCallee` **仍为 true**。

随后进入 args 发射区（line 2538+），`asCallCallee_` 依旧是 true。`visit(IdentifierExpr&)` line 199-213 的自引用检查命中后错误返回过程名而非返回值变量。

Debug 确认（stderr fprintf）：
```
[DBG-FIX032] self-ref HIT name=LocalHostName lower=localhostname retVar=vb6_ret_LocalHostName kind=4 asCallCallee=1
```

### Bug B: PropertyDecl 中 currentProc_ 指向错误符号

`visit(PropertyDecl&)` 在 cgen_decl.cpp:946 用 `symTab_.lookupModule(node.name)` 查找属性符号。但 `Scope::lookupLocal()` 的优先级是 非Property > PropertyGet > PropertyLet > PropertySet。所以对于 `Property Let SockOpt`，`lookupModule("SockOpt")` 总是返回 **PropertyGet** 符号（$pg 后缀优先级最高）。

后果：Property Let/Set 生成体时，`currentProc_` 指向同名 PropertyGet 符号 —— 其 `params` 列表只有 Get 版本的参数，**缺少 Let/Set 最后一个赋值 RHS 参数**（如 Value）。

`visit(IdentifierExpr&)` line 311-332 的 ByRef/ByVal 形参短路检查通过 `currentProc_->params` 遍历，找不到 `Value` 形参，于是 fallthrough 到 PropertyGet 裸引用路径（line 719-736），生成 `vb6_cCsv_prop_get_Value((void*)me)`（跨模块同名属性误命中）。

## 修复

### Fix A: RAII CallCalleeValueScope（cgen_expr.cpp:2165-2178）

在 callee 发射完成后立即插入 RAII 结构，将 `asCallCallee_` 强制为 false 并保存原值。函数退出时（任何 return 或自然走到末尾，共 16 处早返回点）自动恢复：

```cpp
struct CallCalleeValueScope {
    bool& ref;
    bool saved;
    CallCalleeValueScope(bool& r, bool s) : ref(r), saved(s) { ref = false; }
    ~CallCalleeValueScope() { ref = saved; }
} _argsValueScope{asCallCallee_, savedAsCallCallee};
```

### Fix B: cgen_decl.cpp:946 用 lookupModuleByKind 精确查找

```cpp
SymbolKind propSk;
switch (node.propKind) {
    case ProcKind::PropertyGet:  propSk = SymbolKind::PropertyGet; break;
    case ProcKind::PropertyLet:  propSk = SymbolKind::PropertyLet; break;
    case ProcKind::PropertySet:  propSk = SymbolKind::PropertySet; break;
    default:                     propSk = SymbolKind::PropertyGet; break;
}
auto* propSym = symTab_.lookupModuleByKind(node.name, propSk);
currentProc_ = propSym;
```

与 semantic_analyzer.cpp:775 Pass2 行为一致。
