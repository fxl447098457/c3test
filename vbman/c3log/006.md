## Fix 006a: ReDim 语句支持 With 块前缀点号 (`.Member`)

### 问题
VB6 的 `ReDim` 语句在 With 块内使用时，变量名以点号开头引用 With 对象成员：

```vb
With m_oSocket
    ReDim Preserve .SocketPtr(0 To lSize - 1) As Long
End With

ReDim .Data(0 To dataSize - 1) As Byte
```

`parseReDimStmt()` 在解析变量名时直接调用 `expectName()`，期望第一个 token 是标识符。当遇到 `.` (Dot) 时报错 "expected variable name"。

### 根因分析
`parser_stmt.cpp` 第 909 行：
```cpp
auto varTok = expectName("expected variable name");
std::string varName = varTok.text;
```

已有 `while (match(TokenKind::Dot))` 循环处理 `obj.Member` 形式的点访问（Fix 005b），但缺少对 With 块前导 `.` 的支持。

### 修复
在 `expectName()` 之前添加前导点号检测：

```cpp
// 解析变量名, 支持点访问: uOutput.Buffer 和 With块: .Member
std::string varName;
if (match(TokenKind::Dot)) {
    varName = ".";
}
auto varTok = expectName("expected variable name in ReDim");
varName += varTok.text;
```

### 受影响文件
- `cAsyncSocket.cls` (line 1799): `ReDim Preserve .SocketPtr(0 To lSize - 1) As Long`  → PASS
- `mQRcodeGen.bas` (line 439): `ReDim .Data(0 To ...) As Byte`  → PASS

### 修改位置

## Fix 006b: `Rem` 关键字作为注释处理

### 问题
4 个 GBK 编码的源文件在第 293、560、356、86 行处报 VB1005 编码错误。这些行全部是 `Rem` 注释行，包含中文字符。

例如 `cHttpClient.cls`:
```vb
Rem 这是一个中文注释，包含 GBK 编码的中文字符
```

### 根因分析
C3 词法分析器将 `Rem` 登记在关键字表 (`{"rem", TokenKind::REM_keyword}`，`lexer.cpp` 第 117 行)，但 `scanIdentifierOrKeyword()` 识别到 `REM_keyword` 后仅返回关键字 token，不消费后续行内容。

只有 `'` 单引号触发 `scanComment()`，`Rem` 不触发。因此 `Rem` 后的中文文本（GBK→UTF-8 转换后的多字节序列）被当作代码解析，字节 ≥ 0x80 命中 `scanToken()` default 分支，产生 VB1005 编码错误。

额外发现：`ToolsJs.bas` 之前因超时被标记为 CRASH，修复后变为 PASS。推测其超时也是 `Rem` 行中文字符引起的解析卡死。

### 修复
在 `scanIdentifierOrKeyword()` 的关键字查找后，新增 `Rem` 特殊处理：

```cpp
auto it = keywords_.find(lower);
if (it != keywords_.end()) {
    // Rem 关键字: 作为注释处理, 消费到行尾 (与 ' 注释行为一致)
    if (it->second == TokenKind::REM_keyword) {
        while (offset_ < content_.size() && peek() != '\n') {
            text += advance();
        }
        return makeToken(TokenKind::Comment, text, startLine, startCol);
    }
    return makeToken(it->second, text, startLine, startCol);
}
```

逻辑与 `scanComment()` 一致：消费到行尾，返回 `TokenKind::Comment`。

- `cToolsStr.cls` (line 560) → PASS
- `cToolsHttp.cls` (line 356) → PASS
- `cToolsUtf8.cls` (line 86) → PASS
- `ToolsJs.bas` (已修复 CRASH/超时) → PASS (额外收获)
