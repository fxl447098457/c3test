# Fix 051: Set 语句 void*→VARIANT 包装 + DLL dispatch Variant 处理 + wrapVariantValue 修复

## 日期
2026-07-23

## 问题描述

### 根因1: Set 语句未包装 void* → vb6_VARIANT (57 个 C2440 错误)

在 `visit(SetStmt&)` (cgen_stmt.cpp:1106) 中，Set 语句直接赋值 `target = value;` 而不检查目标是否为 Variant。当目标是 Variant 变量（如 `vb6_ret_Xxx`、`Dim x As Variant`）而值是 `void*`（对象指针，如 `vb6_ComCallObject` 返回值、类字段访问），产生 `void* → vb6_VARIANT` C2440 错误。

典型示例（cJson.c）:
```c
// Set TmpO = me->RootItems  →  void* 赋值给 vb6_VARIANT
TmpO = me->RootItems;  /* Set */  // C2440!
```

### 根因2: wrapVariantValue 误判 vb6_VariantTo* 函数为 Variant

`wrapVariantValue()` (cgen_util.cpp:2286) 检查 `cExpr.find("vb6_Variant") == 0` 来判断值是否已是 Variant。但 `vb6_VariantToObjectVal()` 返回 `void*`，`vb6_VariantToString()` 返回 `BSTR`，都不是 `vb6_VARIANT`。这些函数被错误地跳过包装。

### 根因3: DLL dispatch Variant 返回值用 (intptr_t) 强转 (37 个 C2440 错误)

在 DLL 入口分派代码生成中 (cgen_util.cpp:341)，Variant 返回类型的函数走 else 分支：
```c
((VARIANT*)result)->lVal = (int32_t)(intptr_t)_r;  // _r 是 vb6_VARIANT 结构体，不能 cast 为 intptr_t
```

### 根因4: DLL dispatch Variant 参数传递不正确

在分派代码中，ByVal Variant 参数走 else 分支传递 `lVal`（int32_t），ByRef Variant 参数走 else 分支传递 `(void*)&lVal`。但 C 函数期望 `vb6_VARIANT`（ByVal）或 `vb6_VARIANT*`（ByRef）。

## 修复方案

### 修改1: Set 语句添加 Variant 目标包装

**文件**: `src/backend/cgen_stmt.cpp` (Set 语句末尾)

在 `c_.emitLine(target + " = " + value + ";  /* Set */");` 之前，检查目标是否为 Variant（通过 `knownVariantVars_`）。如果是，且值未已包装为 `vb6_VariantFromValue` 或 `vb6_VariantFromComResult`，则用 `vb6_VariantFromValue` 包装。

`vb6_VariantFromValue` 是 `_Generic` 宏：
- `void*` → `vb6_VariantObject` (包装对象指针)
- `vb6_VARIANT` → `vb6_VariantIdentity` (no-op, 安全)
- `BSTR` → `vb6_VariantString`
- 其他标量 → 对应 Variant 构造函数

因此始终包装是安全的，只需避免双重包装。

### 修改2: wrapVariantValue 排除 vb6_VariantTo* 函数

**文件**: `src/backend/cgen_util.cpp` (wrapVariantValue 函数)

将 `cExpr.find("vb6_Variant") == 0` 改为 `(cExpr.find("vb6_Variant") == 0 && cExpr.find("vb6_VariantTo") != 0)`，使 `vb6_VariantToObjectVal`、`vb6_VariantToString` 等返回具体类型的函数不再被误判为已是 Variant，从而正确走 `vb6_VariantFromValue` 包装路径。

### 修改3: DLL dispatch Variant 返回值用 memcpy

**文件**: `src/backend/cgen_util.cpp` (DLL 入口分派代码生成)

在返回值处理中添加 Variant 分支：
```cpp
} else if (methodSym->type == Vb6Type::Variant) {
    entry.emitLine("memcpy(result, &_r, sizeof(vb6_VARIANT));");
}
```

`vb6_VARIANT` 与 Windows `VARIANT` 布局兼容（vt + padding + union，16 字节），可直接 memcpy。

### 修改4: DLL dispatch Variant 参数正确传递

**文件**: `src/backend/cgen_util.cpp` (分派代码参数构建)

- ByVal Variant: `*(vb6_VARIANT*)args[i]` — 解引用传递整个 VARIANT 结构
- ByRef Variant: `(vb6_VARIANT*)args[i]` — 传递 VARIANT 指针

## 修改文件

1. `src/backend/cgen_stmt.cpp` — Set 语句添加 Variant 目标检测 + `vb6_VariantFromValue` 包装
2. `src/backend/cgen_util.cpp` — wrapVariantValue 排除 `vb6_VariantTo*`；DLL dispatch Variant 返回值 memcpy；DLL dispatch Variant 参数正确传递
