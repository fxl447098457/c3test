## 根本原因

### CStr 特殊处理覆盖不全 (cgen_expr.cpp:3382-3425)

CStr 的 callee-rewrite 特殊分支根据参数类型选择 `vb6_CStrLong`/`vb6_CStrDbl`/或保留 `vb6_CStr(VARIANT)`:
- **IdentifierExpr 分支**: 检查 knownBstrVars_ / knownLongVars_ / knownDoubleVars_。仅这三种类型 + 已知 Variant 被处理。
- **非 IdentifierExpr 分支**: 用 inferExprType 检查 Long/Double, 然后 COM 模式检查。

**遗漏的类型**: Boolean / Byte / Date / Currency / 常量 / 未注册函数返回值 / Const BSTR / Unknown — 这些情况下 callee 保持 `vb6_CStr` (接 `vb6_VARIANT`), 但实际参数是具体类型 → C2440 (concrete → VARIANT)。

### Format 特殊处理覆盖不全 (cgen_expr.cpp:3487-3507)

Format 的 args[0] 包装按 Long/Double/String/Boolean/Byte/Date 选择 Variant ctor。
**遗漏**: Currency / Unknown 类型 → args[0] 未包装 → vb6_Format 接 VARIANT, 具体 arg 直传 → C2440。

### CInt/CLng/CDbl 检测不全 (cgen_expr.cpp:3428-3445)

CInt/CLng/CDbl 接 `double`, 有 V 后缀变体 (`vb6_CIntV` 等) 接 VARIANT。
原有代码仅检查 IdentifierExpr 的 knownVariantVars_。
**遗漏**:
1. BSTR 参数 → `BSTR → double` C2440 (需 `vb6_Val` 转换)
2. 非 IdentifierExpr 的 Variant 表达式 (函数返回 Variant 的调用/类方法) → 不会被检测为 Variant, 不切换到 V 后缀

## 修复方案

### 1. CStr fallback (cgen_expr.cpp, 最终 emit 前)

在所有 callee-rewrite 块之后, 最终 `lastExpr_ = callee + "(" + argList + ")"` 之前:

```cpp
if (callee == "vb6_CStr" && !args.empty()) {
    bool argIsDefVariant = false;
    if (!node.positional.empty()) {
        argIsDefVariant = isDefinitelyVariantExpr(*node.positional[0]);
    }
    if (!argIsDefVariant) {
        args[0] = "vb6_VariantFromValue(" + args[0] + ")";
        argList.clear();
        for (size_t i = 0; i < args.size(); i++) {
            if (i > 0) argList += ", ";
            argList += args[i];
        }
    }
}
```

**关键**: 用 `isDefinitelyVariantExpr` 守卫, 跳过确定 Variant 的表达式 (如 `Me.Segments(i)` 返回 Variant)。
`vb6_VariantFromValue` 是 `_Generic` 宏, 对 Variant 表达式展开可能产生逗号问题 → C2197 (实测确认: 6 个 cHttpServerRouteItem.c 的 C2197 回归)。守卫消除此回归。

对非 Variant 的具体类型实参, `_Generic` 按实参 C 类型自动选择 Variant ctor (标量→VariantLong/Int/Double, BSTR→VariantString, class ptr→Object 等), 避免 C2440。

### 2. Format fallback (cgen_expr.cpp:3499 后)

在现有 Date 分支后添加 else:

```cpp
else if (argType != Vb6Type::Variant) {
    args[0] = "vb6_VariantFromValue(" + args[0] + ")";
}
```

覆盖 Currency/Unknown 等未匹配类型。Variant 类型跳过 (已是 vb6_VARIANT)。

### 3. CInt/CLng/CDbl 扩展 (cgen_expr.cpp:3428-3445)

- 新增 `firstArgIsBstr` 检测 (knownBstrVars_)
- 新增 `isDefinitelyVariantExpr` 检测非 IdentifierExpr Variant 表达式
- BSTR 参数 → `vb6_Val(args[0])` 转换为 double (CInt/CLng/CDbl 接 double)
- Variant 表达式 → 切换到 V 后缀变体

```cpp
if (callee == "vb6_CInt" || callee == "vb6_CLng" || callee == "vb6_CDbl") {
    bool firstArgIsVariant = false;
    bool firstArgIsBstr = false;
    // ... IdentifierExpr: check knownVariantVars_ / knownBstrVars_
    // ... non-IdentifierExpr: isDefinitelyVariantExpr
    if (firstArgIsVariant) {
        callee = "vb6_CIntV" / "vb6_CLngV" / "vb6_CDblV";
    } else if (firstArgIsBstr && !args.empty()) {
        args[0] = "vb6_Val(" + args[0] + ")";
        // rebuild argList
    }
}
```

## 影响分析

- **C2440 -36**: CStr fallback 修复 ~25 个 (Boolean/Byte/Const BSTR/未知函数返回值 → VARIANT), CInt/CLng/CDbl 扩展修复 ~11 个 (BSTR → double + Variant 表达式 → V 后缀)。Format fallback 贡献少数。
- **C2197 0 回归**: 首版未加 isDefinitelyVariantExpr 守卫 → +6 C2197 (cHttpServerRouteItem.c 的 `Me.Segments(i)` Variant 表达式被 _Generic 宏展开出逗号)。加守卫后消除。
