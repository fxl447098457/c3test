# Fix 052: DLL dispatch 前向声明签名修复 + Variant 返回值类型检测

## 日期
2026-07-23

## 错误概览
- 修复前: 1303 个总错误, C2440 602 个
- 修复后: 1210 个总错误, C2440 509 个
- 净减少: -93 个总错误, -93 个 C2440

## 根因分析

### 根因1: DLL dispatch 前向声明签名不匹配 (88个 C2440)

`cgen_util.cpp` 生成 `dll_entry.c` 时, 为所有 COM 类的公共方法生成 `extern` 前向声明。
但前向声明使用 `mapType(p.type)` 生成参数类型, 存在两个问题:

1. **ByRef 参数缺少指针**: 前向声明生成 `vb6_VARIANT` (值), 但函数定义是 `vb6_VARIANT*` (指针)
2. **Optional 参数缺少 _has_ 标志**: 前向声明不包含 `int _has_ParamName` 尾部参数

示例 (cHttpServerResponse.Json):
```c
// 前向声明 (错误):
extern void vb6_cHttpServerResponse_Json(struct vb6_cls_cHttpServerResponse*, vb6_VARIANT, int32_t, BSTR, int32_t, vb6_VARIANT);

// 函数定义 (正确):
void vb6_cHttpServerResponse_Json(vb6_cls_cHttpServerResponse* me, vb6_VARIANT* Data, int32_t* Code, BSTR* msg, int32_t* Count, vb6_VARIANT* Whitespace, int _has_Code, int _has_msg, int _has_Count, int _has_Whitespace)
```

这导致 MSVC 以前向声明的签名为准, 报告 `vb6_VARIANT* → vb6_VARIANT` 转换错误 (dispatch 调用传递指针, 但前向声明声明为值)。

### 根因2: dispatch 调用缺少 Optional _has_ 参数

dispatch 调用代码只生成 `methodSym->params` 对应的实参, 不生成 Optional 参数的 `_has_` 标志。
虽然 C 模式下 MSVC 不报 C2198, 但缺少 `_has_` 参数会导致运行时未定义行为。

### 根因3: Variant 返回值类型检测不完整 (3个 C2440)

返回值处理代码检查 `methodSym->type == Vb6Type::Variant` 来决定使用 `memcpy`。
但 `mapType()` 将多种类型映射为 `vb6_VARIANT`: `Variant`, `Decimal`, `UserDefinedType`, 以及 `default` 兜底。
对于 `Decimal`/`UserDefinedType` 返回类型, 代码走了 `(int32_t)(intptr_t)_r` 分支, 试图将 `vb6_VARIANT` 结构体 cast 为 `intptr_t`, 产生 C2440 错误。

## 修复方案

### 修改1: 前向声明添加 ByRef 指针 + Optional _has_ 标志
**文件**: `src/backend/cgen_util.cpp` (line ~236-258)

将前向声明生成逻辑合并为一个块, 对每个参数:
- 如果 `!p.isByVal`, 在 `mapType(p.type)` 后追加 `*` (ByRef → C 指针)
- 遍历 Optional 参数, 追加 `int _has_ParamName`

### 修改2: dispatch 调用添加 Optional _has_ 参数
**文件**: `src/backend/cgen_util.cpp` (line ~333-338)

在实参列表末尾, 为每个 Optional 参数追加 `, 1` (COM dispatch 中所有参数都已提供)。

### 修改3: ByRef String 参数 dispatch 传递
**文件**: `src/backend/cgen_util.cpp` (line ~326-327)

添加 ByRef String 参数的处理: `&((VARIANT*)args[i])->bstrVal` (传递 BSTR 指针)。

### 修改4: Variant 返回值检测改用 retType 字符串
**文件**: `src/backend/cgen_util.cpp` (line ~365)

将 `methodSym->type == Vb6Type::Variant` 改为 `retType == "vb6_VARIANT"`,
覆盖所有映射为 `vb6_VARIANT` 的返回类型 (Variant/Decimal/UDT/未知类型)。
