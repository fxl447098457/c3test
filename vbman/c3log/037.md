# Fix 037: IndexOrCallExpr C2064 — 对象数据字段被当作函数调用

## 错误概述

C2064: "项不会计算为接受 N 个参数的函数" — VB6 中 `obj.field(idx)` 或 `field(idx)` (隐式 Me.)
当 `field` 是对象数据字段 (非函数/属性) 时, C3 codegen 错误地将字段当作函数调用,
生成 `obj->field(idx)` 或 `me->field(idx)`, MSVC 报 C2064.

**初始错误数**: C2064=100, 总错误=2174

## 根因分析

VB6 语义中, `obj.field(idx)` 当 `field` 是对象数据字段时, 实际调用该对象的默认成员
(通常为 `Item` 属性, DISPID_VALUE). C3 codegen 未识别此模式, 直接将字段名作为函数名调用.

### 字段类型分类

| 类型 | C 表示 | 示例 | 处理方式 |
|------|--------|------|----------|
| UDT 固定数组字段 | `Type field[N]` | `uString.IpAddress(0)` | `field[idx]` |
| UDT 动态数组字段 | `vb6_SafeArray1D* field` | `uOutput.Data(lSignPos)` | `VB6_SA_AT(type, field, idx)` |
| 类 Variant 字段 | `vb6_VARIANT field` | `obj.Segments(i)` | `vb6_VariantArrayGet(&field, idx)` |
| 类 void* COM 字段 | `void* field` | `obj.RootItems(Index)` | `vb6_ComCall(field, L"Item", args, argc)` |
| 类 typed 项目类字段 | `vb6_cls_Xxx* field` | `me->Rows(1)` (Rows As cCollection) | `vb6_Xxx_prop_get_Item(field, vb6_VariantFromValue(arg))` |
| 类 typed COM 接口字段 | `vb6_ComIface_Xxx* field` | `Request->Header("Cookie")` (Header As Dictionary) | `vb6_ComCall((void*)field, L"Item", args, argc)` |
| UDT Variant 字段 | `vb6_VARIANT field` (in UDT) | `uFile.SourceFileInfo(0)` | `vb6_VariantArrayGet(&field, idx)` |
| UDT Object 字段 | `void* field` (in UDT) | `uFile.SourceFileInfo(0)` | `vb6_ComCall(field, L"Item", args, argc)` |
| ByRef Object 参数 | `void** param` | `(*Items)(0)` | `vb6_ComCall((*param), L"Item", args, argc)` |
| 局部 Object 变量 | `void* var` | `x(idx)` (Dim x As Object) | `vb6_ComCall(x, L"Item", args, argc)` |
| 隐式 Me.field (void*) | `me->field` | `LangInfo("LangList")` | `vb6_ComCall(me->field, L"Item", args, argc)` |
| 隐式 Me.field (Variant) | `me->field` | `Segments(i)` | `vb6_VariantArrayGet(&me->field, idx)` |

## 模式详解

### Pattern A: UDT 固定数组字段
- **VB6**: `uString.IpAddress(0)` (IpAddress(0 To 15) As Byte in UDT)
- **问题**: 生成 `uString.IpAddress(0)` — C 中数组字段不能用函数调用语法
- **修复**: `uString.IpAddress[0]`

### Pattern B: UDT 动态数组字段
- **VB6**: `uOutput.Data(lSignPos)` (Data() As Byte in UDT)
- **问题**: Data 是 `vb6_SafeArray1D*`, 不能当函数调用
- **修复**: `VB6_SA_AT(uint8_t, uOutput.Data, lSignPos)`
- **基础设施**: ast.hpp TypeMember 添加 `isArrayDynamic` 字段; parser 检测 `()` 语法;
  symbol_table UdtMemberInfo 添加 `isArrayDynamic`; cgen_decl UDT 动态数组字段生成 `vb6_SafeArray1D*`

### Pattern C: 类 Variant 字段 (显式 obj)
- **VB6**: `obj.Segments(i)` (Segments As Variant in class)
- **修复**: `vb6_VariantArrayGet(&obj->Segments, i)`

### Pattern D: 类 void* COM 字段 (显式 obj)
- **VB6**: `obj.RootItems(Index)` (RootItems As New Collection)
- **修复**: `vb6_ComCall(obj->RootItems, L"Item", args, argc)`

### Pattern E: void* 字段嵌套属性
- 通过 MemberAccessExpr 链式访问处理 (voidptr 注释标记机制)

### Pattern F: ByRef Object 参数
- **VB6**: `Items(0)` (Items 是 ByRef Object 参数)
- **C**: `void** Items` → `(*Items)` 是 `void*`
- **修复**: `vb6_ComCall((*Items), L"Item", args, argc)`

### Pattern F2: 局部 Object 变量
- **VB6**: `x(idx)` (Dim x As Object)
- **修复**: `vb6_ComCall(x, L"Item", args, argc)`

### Pattern G: 隐式 Me.field (void*/Variant)
- **VB6**: `LangInfo("LangList")` (类模块内, LangInfo 是 void* 数据字段)
- **问题**: codegen 为 IdentifierExpr 添加 `me->` 前缀, 生成 `me->LangInfo("LangList")`
  — LangInfo 不是函数 → C2064
- **修复**: 
  - void* 字段 → `vb6_ComCall(me->LangInfo, L"Item", args, argc)`
  - Variant 字段 → `vb6_VariantArrayGet(&me->LangInfo, idx)`
- **关键**: IdentifierExpr callee 拦截 (非 MemberAccessExpr), 检查 isClassModule_ &&
  !knownLocalVars_ && !isParam

### Pattern H: UDT Object (void*) 字段
- **VB6**: `uFile.SourceFileInfo(0)` (SourceFileInfo As Variant/Object in UDT)
- **修复**: `vb6_ComCall(uFile.SourceFileInfo, L"Item", args, argc)`

### Pattern J: UDT Variant 字段
- **VB6**: 同 Pattern H 但字段类型为 Variant
- **修复**: `vb6_VariantArrayGet(&uFile.SourceFileInfo, idx)`

### Pattern K: COM 接口字段 (Fix 037b 新增)
- **VB6**: `Request->Header("Cookie")` (Header As Dictionary — COM 接口类型)
- **C**: `vb6_ComIface_IDictionary* Header` — 非 void*, 非 Variant, 非 项目类
- **问题**: 既不在 classVoidFieldMap_ 也不在 classVariantMembers_ → 拦截未触发
- **修复**: `vb6_ComCall((void*)Request->Header, L"Item", args, argc)`

### Pattern L: 项目类 typed 字段 (Fix 037b 新增)
- **VB6**: `me->Rows(1)` (Rows As cCollection — 项目类实例)
- **C**: `vb6_cls_cCollection* Rows` — 非 void*, 非 Variant, 非 COM 接口
- **问题**: 同 Pattern K, 不在任何现有字段类型表中
- **修复**: `vb6_cCollection_prop_get_Item(me->Rows, vb6_VariantFromValue(1))`
  - 通过 `resolveClassMemberCall(fieldType, "Item")` 解析 C 函数名
  - 参数包装: `vb6_VariantFromValue(arg)` (Item 属性参数为 ByVal Variant)
  - Set 语句上下文: 自动包装 `vb6_VariantToObjectVal(...)` 提取对象引用

## 实现细节

### 1. driver.cpp: classTypedFieldMap 构建

新增全局映射 `classTypedFieldMap`:
- key: 类名 (如 "cDataBase")
- value: (字段名小写 → VB6类型名)
  - 项目类字段 → 存储类名 (如 "cCollection")
  - COM 接口字段 → 存储 "COM:" + 类型名 (如 "COM:Dictionary")

扫描逻辑复用 `isVoidFieldType` 排除 void* 字段, 然后在符号表中查找类型:
- `SymbolKind::Class` → 项目类
- `SymbolKind::ComClass/ComInterface` → COM 接口

### 2. cgen.hpp: 新增字段和构造函数参数

- `classTypedFieldMap_` — const 指针, 指向 driver 构建的全局映射
- `lastExprNeedsObjectUnpack_` — 布尔标记 (已被字符串检测替代, 保留清除)
- 构造函数新增 `classTypedFieldMap` 参数

### 3. cgen_expr.cpp: 拦截逻辑

#### IdentifierExpr callee 路径 (Pattern G 扩展)
在 void* 检查之后, 新增 `else if (classTypedFieldMap_)` 分支:
- 查找当前模块名 (moduleName_) 在 classTypedFieldMap_ 中的条目
- 匹配字段名 (原名小写 + m_ 前缀小写)
- COM 字段 (Pattern K) → `vb6_ComCall((void*)me->field, L"Item", args, argc)`
- 项目类字段 (Pattern L, argc==1) → `resolveClassMemberCall(fieldType, "Item")` + `vb6_VariantFromValue(arg)`

#### MemberAccessExpr callee 路径 (Pattern D 扩展)
在 void* 检查之后, 同样新增 `else if (classTypedFieldMap_)` 分支:
- `className = inferClassTypeOfExpr(*maExpr.object)` 推断对象类类型
- 在 classTypedFieldMap_ 中查找字段类型
- 同上分派 COM/项目类

### 4. cgen_util.cpp: inferClassTypeOfExpr 扩展

新增 `MemberAccessExpr` case, 支持链式访问的类型推断:
- 递归推断 `ma.object` 的类类型
- 在 classTypedFieldMap_ 中查找 `ma.memberName` 的字段类型
- 仅返回项目类字段类型 (COM: 前缀的返回空)
- 示例: `ctx.Request` → ctx(cHttpServerContext) → Request(cHttpServerRequest)

### 5. cgen_stmt.cpp: Set 语句 VARIANT→void* 转换

在 `vb6_ComCall → vb6_ComCallObject` 转换之后, 新增字符串检测:
- 检测 value 以 "vb6_" 开头且第一个 '(' 恰在 "_prop_get_Item" 之后
- 匹配 → `value = "vb6_VariantToObjectVal(" + value + ")"`
- 确保仅匹配顶层 Item 调用 (非嵌套), 避免误包装

### 6. cgen_base.cpp: Variant 成员扫描

classVariantMembers_ 在类成员扫描阶段填充, 检测 Variant 类型字段
(包括 m_ 前缀和无前缀两种形式).

### 7. cgen_decl.cpp: UDT 动态数组字段

UDT 成员声明中 `()` 语法 (如 `Data() As Byte`) 标记为动态数组,
生成 `vb6_SafeArray1D* Member` 而非标量类型.
