# c3log 003: 函数体内 Const 声明双重 advance 消费了常量名

## 日期
2026-07-15

## 问题概述

修复 Fix 002 后，仍有 7 个文件报 "expected Const name (got Token/=)" 错误。所有错误均为函数体/属性体内的局部 `Const` 语句，例如：

```vb
Public Function FindItem(...) As TypeRegData()
    Const Q As String = "reg query "      ' ← error VB2001: expected Const name (got Token)
```

## 根因分析

`parseConstStmtInBody()`（`parser_stmt.cpp:932`）和 `parseConstDecl()`（`parser_decl.cpp:304`）存在**双重 advance** bug：

```cpp
// parser_stmt.cpp — 旧代码
StmtPtr Parser::parseConstStmtInBody() {
    advance();                  // ← 消费 'Const'
    auto constDecl = parseConstDecl(AccessLevel::Private);  // ← 内部又 advance() 一次!
    ...
}

// parser_decl.cpp
std::unique_ptr<ConstDecl> Parser::parseConstDecl(AccessLevel access) {
    advance();                  // ← 再次消费，但 'Const' 已被消费，这次吃掉了常量名!
    auto nameTok = expectName("expected Const name");  // ← 此时游标在 'As' 或 '=' 上 → 报错
    ...
}
```

执行流程（以 `Const Q As String = "reg query "` 为例）：
1. `parseConstStmtInBody()` → `advance()` 消费 `Const` → 游标在 `Q`
2. `parseConstDecl()` → `advance()` 消费 `Q`（以为是 `Const`） → 游标在 `As`
3. `expectName()` 看到 `As` → 报错 "expected Const name (got Token)"

对于 `Const SW_SHOWNORMAL = 1`（无 `As` 子句）：
1. `advance()` 消费 `Const` → 游标在 `SW_SHOWNORMAL`
2. `advance()` 消费 `SW_SHOWNORMAL` → 游标在 `=`
3. `expectName()` 看到 `=` → 报错 "expected Const name (got =)"

**对比**：模块级 `Const` 不存在此问题，因为 `parseDeclaration()` → `parseConstDeclList()` → `parseConstDecl()` 只 advance 一次。函数体外 `Const` 的流程正确；只有函数体内 `Const` 有双重 advance。

**为什么 `parseStaticStmtInBody()` 和 `parseAccessDeclInBody()` 没有此问题？** 因为 `parseVariableDecl()` 有条件性 advance 守卫：
```cpp
if (cur_.kind == Dim || Public || Private || Static || ...) { advance(); }
```
如果关键字已被调用方消费，此条件不成立，不会重复 advance。而 `parseConstDecl()` 是无条件 advance。

## 修复

### 修改 1: `parseConstStmtInBody()` — 移除多余 advance，改用 parseConstDeclList

```cpp
// 旧:
advance(); // consume 'Const'
auto constDecl = parseConstDecl(AccessLevel::Private);
return std::make_unique<LocalDeclStmt>(loc, std::move(constDecl));

// 新:
// 不需要 advance() — parseConstDeclList -> parseConstDecl 会消费 'Const'
auto decl = parseConstDeclList(AccessLevel::Private);
return std::make_unique<LocalDeclStmt>(loc, std::move(decl));
```

改用 `parseConstDeclList()` 同时为局部 `Const` 添加了逗号分隔支持（如 `Const A = 1, B = 2`）。

### 修改 2: `parseStaticStmtInBody()` — 改用 parseVariableDeclList（逗号支持）

```cpp
// 旧:
auto varDecl = parseVariableDecl(AccessLevel::Private, true);
// 新:
auto varDecl = parseVariableDeclList(AccessLevel::Private, true);
```

### 修改 3: `parseAccessDeclInBody()` — 改用 parseVariableDeclList（逗号支持）

```cpp
// 旧:
auto varDecl = parseVariableDecl(access, false);
// 新:
auto varDecl = parseVariableDeclList(access, false);
```
