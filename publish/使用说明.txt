================================================================
  C3 - 第三代 VB6 编译器  v0.11.0  使用说明
================================================================

一、简介
----------------------------------------------------------------

C3 是现代化 Visual Basic 6.0 编译器，将 VB6 代码编译为原生
x64 / x86 Windows 可执行文件 (.exe) 和动态链接库 (.dll)。

核心能力：
  - x64 / x86 双架构原生编译（突破 2GB 内存限制）
  - Unicode (UTF-16) 字符串全程支持
  - 多线程运行时（告别 STA 单线程单元）
  - COM 客户端/服务端 + ActiveX DLL 编译
  - 内建类型库生成（无需额外工具）
  - 一体化封装（单文件即可编译，零配置）
  - VBP 工程文件支持
  - GBK/UTF-8/UTF-16 源码自动识别
  - FRX 二进制资源读取（图标、图片、ImageList）
  - VS_VERSION_INFO 资源嵌入（文件版本、公司名等）
  - 359+ 内建常量全面覆盖

二、目录结构
----------------------------------------------------------------

  C3.exe              编译器
  msvc\               内置迷你 MSVC 工具链（离线模式 zip ~78 MB）
    vcvars.bat        环境配置脚本（设置 INCLUDE/LIB/PATH）
    bin\              cl.exe, link.exe 及编译器 DLL
    include\          MSVC + Windows SDK 头文件
    lib\x64\          CRT + Windows SDK 链接库
  demos\              示例工程
    hello\            控制台入门（Hello World + 循环 + 函数）
    com_client\       COM 客户端（CreateObject + 后期绑定）
    activex_dll\      ActiveX DLL（VBP + 类模块 + CLSID）
    win32_form\       Win32 窗体应用（控件 + 事件）
    multimodule\      多模块 VBP 工程（跨模块符号引用）

三、开箱即用
----------------------------------------------------------------

C3 为一体化封装设计，编译所需的一切均已内置，无需额外配置
路径、环境变量或安装附属组件。拿到 C3.exe 即可直接编译。

四、环境要求
----------------------------------------------------------------

编译需要 Microsoft Visual C++ (MSVC)，有两种方式：

  方式 A -- 内置迷你工具链（推荐，免安装）
    发布包自带 msvc\ 目录（zip ~78 MB），无需联网安装 VS
    使用前执行: call msvc\vcvars.bat
    即可配置好 cl.exe / link.exe / INCLUDE / LIB 等环境
    一键安装脚本 (install_msvc.bat) 会自动检测并使用此目录

  方式 B -- 本机已安装 Visual Studio
    安装 Visual Studio 2022 Community（免费）
    安装时勾选"使用 C++ 的桌面开发"
    C3 会自动检测 MSVC 环境（无需手动运行 vcvarsall.bat）
    如已手动运行 vcvarsall.bat，C3 将直接使用当前环境

五、快速开始
----------------------------------------------------------------

1. 控制台程序

   C3 hello.bas -o hello.exe
   hello.exe

2. COM 客户端程序

   C3 com_client.bas -o com_client.exe
   com_client.exe

3. ActiveX DLL

   C3 test_activex_dll.vbp -o MyDLL.dll
   regsvr32 MyDLL.dll

4. Win32 窗体程序

   C3 simple_form.frm -o SimpleForm.exe
   SimpleForm.exe

5. 多模块 VBP 工程

   C3 TestVBP.vbp -o TestVBP.exe
   TestVBP.exe

六、命令行参数
----------------------------------------------------------------

  C3 <源文件或VBP> [选项]

  选项：
    -o, --output <路径>      输出文件路径（.exe / .dll）
    --output-dir <目录>      输出目录（默认: 源文件所在目录）
    --dll                    编译为 ActiveX DLL
    --progid <前缀>          ActiveX DLL 的 ProgID 前缀
    --define <宏=值>         定义条件编译常量（#Const）
    --typelib <路径>         导入 TypeLib（早期绑定）
    --no-auto-typelib        禁用自动 TypeLib 导入
    -O <级别>                优化级别（0-3）
    -g, --debug              生成调试信息
    --keep-for-debug         保留中间 C 代码文件（编译后不删除）
    -v, --verbose            详细输出
    --dump-tokens            输出词法分析结果
    --dump-preprocess        输出预处理结果
    --dump-frm               输出窗体解析结果
    -h, --help               显示帮助信息
    -V, --version            显示版本信息

七、编译失败排查
----------------------------------------------------------------

  编译失败时，C3 会在输出目录生成 C3-error.log 文件，
  包含完整的诊断信息。例如：

    C3: 编译失败 (exit code 2)
    C3: 错误日志已保存: output/C3-error.log

  查看错误日志即可定位问题。
