# C3 编译器 - 发布包

> C3 是第三代 VB6 编译器,将 VB6 代码编译为原生 x64 Windows 二进制。
> 本目录提供开箱即用的 MSVC 工具链安装 + C3 部署 + 右键菜单一站式脚本。

## 目录内容

```
publish/
├── C3.exe                        C3 编译器主程序
├── install_msvc.bat              一键安装脚本 (MSVC + 部署 + 右键菜单 + 环境变量)
├── msvc/                         内置迷你 MSVC 工具链 (离线模式, zip ~78 MB)
│   ├── vcvars.bat                环境配置脚本 (供独立命令行会话调用)
│   ├── bin/                      cl.exe, link.exe 及编译器 DLL
│   │   ├── 1033/clui.dll         编译器语言资源 (en-US)
│   │   └── 2052/clui.dll         编译器语言资源 (zh-CN)
│   ├── include/                  MSVC + Windows SDK 头文件 (um/shared/ucrt)
│   └── lib/x64/                  CRT + Windows SDK 链接库
├── menu/
│   ├── c3_compile.bat            右键菜单调用脚本 (零配置, 读取用户环境变量)
│   ├── c3_right_click.reg        右键菜单注册表 (安装)
│   └── c3_right_click_remove.reg 右键菜单注册表 (卸载)
└── demos/                        示例工程
```

## install_msvc.bat 说明

C3 编译器使用 MSVC 后端产出原生 x64 二进制,需要本机已安装 MSVC 工具链
(cl.exe + link.exe + Windows SDK)。本脚本提供两种模式:

- **离线模式**: 发布包自带迷你 MSVC 工具链 (`msvc/` 目录, zip ~78 MB),
  无需联网下载 3-5 GB 的完整 VS Build Tools
- **在线模式**: 若本机未检测到 MSVC 且发布包不含 `msvc/` 目录,
  则自动下载安装 VS 2022 Build Tools

### 功能

1. **检测 MSVC 工具链** (按优先级)
   - 优先: 检测 `msvc\vcvars.bat` -> 离线模式,直接使用内置工具链
   - 其次: 检测本机已安装的 VS 2022 / Build Tools -> 跳过安装
   - 最后: 均未检测到 -> 下载安装 VS 2022 Build Tools

2. **离线模式** (发布包含 `msvc/` 目录时)
   - 内置 MSVC 14.44 + Windows SDK 10.0.22621.0
   - 含 cl.exe/link.exe + CRT + 全量 Windows SDK 头文件 (zip ~78 MB vs 完整安装 3-5 GB)
   - 无需联网,安装耗时数秒

3. **静默下载安装 VS 2022 Build Tools** (仅在线模式)
   - 仅安装 `VCTools` 工作负载 + `x86/x64 编译工具` + `Windows 11 SDK`
   - 不安装 VS 集成开发环境 (IDE)
   - 默认安装目录 `C:\BuildTools`,占用约 3-5 GB
   - 预计安装耗时 10-30 分钟 (取决于网络速度)

4. **部署 C3 编译器到 C:\pro\c3**
   - 将本目录所有文件 (含 C3.exe、msvc 子目录、menu 子目录) 复制到 `C:\pro\c3`
   - 如已在目标目录运行则自动跳过复制

5. **安装右键菜单 "使用 C3 编译"**
   - 导入 `C:\pro\c3\menu\c3_right_click.reg` 注册表
   - 安装后右键任意文件即可看到 "使用 C3 编译" 菜单项
   - 点击后弹出编译窗口,可输入编译参数并执行

6. **配置环境变量 (PATH + MSVC 工具链)**
   - 将 `C:\pro\c3` 和 `C:\pro\c3\msvc\bin` 加入用户 PATH
   - 离线模式下永久写入以下用户环境变量 (HKCU\Environment),零配置调用 MSVC:
     - `VCINSTALLDIR` = `C:\pro\c3\msvc` (C3 据此判定 MSVC 就绪)
     - `INCLUDE` = MSVC + SDK 头文件路径
     - `LIB` = MSVC + SDK 链接库路径
   - 新开命令行窗口或右键菜单即可直接编译,无需手动 `call vcvars.bat`

7. **输出 C3 用法说明**

### 用法

1. 下载整个 `publish` 目录 (保持目录结构不变)
2. 右键点击 `install_msvc.bat` -> **以管理员身份运行**
3. 等待安装完成 (离线模式仅需数秒,在线模式 10-30 分钟)
4. 安装完成后:
   - **右键菜单**: 右键任意 VB6 文件 -> "使用 C3 编译"
   - **命令行**: 新开任意命令行窗口,直接执行 `c3 工程文件.vbp`
   - 环境变量已永久写入,无需每次 `call vcvars.bat`

### msvc/ 内置工具链详情

| 项目 | 内容 |
|------|------|
| 编译器 | MSVC 19.44 (cl.exe + c1/c1xx/c2 + link.exe) |
| SDK | Windows 10.0.22621.0 (um 1504 头文件 + shared 242 头文件 + ucrt) |
| 语言资源 | clui.dll (en-US 1033 + zh-CN 2052),避免 C1510 错误 |
| 体积 | zip 压缩包 ~78 MB (展开后 ~320 MB, vs 完整 VS Build Tools 3-5 GB) |
| 配置 | install_msvc.bat 已永久写入 VCINSTALLDIR/INCLUDE/LIB,无需手动 call |
| 路径 | INCLUDE/LIB/PATH 均指向 `msvc\` 子目录 |

### 安装选项说明 (仅在线模式)

脚本启动 `vs_BuildTools.exe` 时传入以下参数:

| 参数 | 说明 |
|------|------|
| `--quiet` | 静默安装,不弹 UI |
| `--norestart` | 安装完成不自动重启 |
| `--wait` | 等待安装完全结束才返回 |
| `--nocache` | 不缓存安装包,装完即清 |
| `--installPath C:\BuildTools` | 指定安装路径 |
| `--add Microsoft.VisualStudio.Workload.VCTools` | VCTools 工作负载 |
| `--add Microsoft.VisualStudio.Component.VC.Tools.x86.x64` | x64/x86 编译器 |
| `--add Microsoft.VisualStudio.Component.Windows11SDK.22621` | Win11 SDK |

如需修改安装选项 (如更换 SDK 版本/添加其他组件),请直接编辑
`install_msvc.bat` 中对应行。

### 卸载

- **卸载右键菜单**: 双击运行 `C:\pro\c3\menu\c3_right_click_remove.reg`
- **清除环境变量** (仅离线模式): 删除以下用户环境变量 (HKCU\Environment)
  - `VCINSTALLDIR`
  - `INCLUDE`
  - `LIB`
  - PATH 中的 `C:\pro\c3` 和 `C:\pro\c3\msvc\bin` 条目
  - 可用「系统属性 -> 环境变量」GUI 或 `setx` / `reg delete` 命令操作
- **删除 C3 编译器**: 删除 `C:\pro\c3` 目录
- **卸载 MSVC Build Tools** (仅在线模式): 控制面板 -> 程序与功能 ->
  "Visual Studio Build Tools 2022" -> 右键卸载

### 常见问题

**Q: 安装失败,提示错误码 xxx?**
A: 常见原因:网络中断 / 磁盘空间不足 / 已有 VS 安装冲突。请关闭其他
VS 安装程序,重启系统后再次运行。脚本会自动跳过已安装的组件。

**Q: 已经安装了 VS 2022 Community,还需要运行此脚本吗?**
A: 不一定。若你的 VS 已勾选「使用 C++ 的桌面开发」工作负载,脚本会
自动检测到并跳过安装,仅执行 C3 部署和右键菜单安装。

**Q: 离线模式 (msvc/) 和在线安装有什么区别?**
A: 离线模式自带精简的 MSVC 工具链 (zip ~78 MB),无需联网,数秒即可完成,且环境变量已自动永久写入。在线安装需要下载完整的 VS Build Tools (3-5 GB),耗时 10-30 分钟。两者编译出的 C3 产物完全相同。发布包若含 `msvc/` 目录则自动走离线模式。

**Q: 右键菜单没出现?**
A: 请确认以管理员权限运行了 install_msvc.bat。若仍不显示,可手动双击
`C:\pro\c3\menu\c3_right_click.reg` 导入注册表,然后重启资源管理器
(任务管理器 -> 重新启动 "Windows 资源管理器")。

**Q: 安装后如何使用 C3?**
A: 最简单方式:右键点击 VB6 文件 -> "使用 C3 编译"。
命令行 (离线模式环境变量已永久写入,新开窗口直接用):
```
c3 hello.bas
```
若在同一窗口手动配置 (不依赖已写入的环境变量):
```
call "C:\pro\c3\msvc\vcvars.bat"
C:\pro\c3\C3.exe hello.bas
```
系统 VS 命令行:在开始菜单搜索 "x64 Native Tools Command Prompt for VS 2022":
```
cd 你的VB6工程目录
C:\pro\c3\C3.exe hello.bas
```
