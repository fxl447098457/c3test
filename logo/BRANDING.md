# C3 Logo 品牌叙事

> C3 编译器视觉标识设计理念与宣发文案

---

## 核心意象

**深邃星空般的深蓝渐变背景下，一个火热的 C3 横空出世。**

C3 一词使用红温底色渐变到黄色，代表了正在燃烧。

---

## 设计语言

### 背景 — 深邃星空

深蓝渐变背景，如无垠星空般深邃。象征着 VB6 所处的时代纵深——这门语言承载了二十余年的工程积淀，而 C3 正是在这片厚重的技术星空下诞生的新一代编译器。

### 字形 — C³ 同构

C 与 3 共享边界，字符同构融合为一个整体。C 的右开口恰好成为 3 的左轮廓，两者你中有我、我中有你，一个图形同时读出两个字符。

- **C** — Compiler，编译器；也是 C 代码生成后端，C3 的技术根基
- **3** — 第三代，从 VB6 原生编译器（c2.exe）到 C3 的三代跨越
- **同构** — 源码与二进制、VB6 与 x64、过去与未来，在 C3 中融为一体

### 渐变 — 燃烧

字符采用从顶部柠黄到底部亮橙的暖色温渐变，色温由冷亮过渡到炽热。这不是静态的涂色，而是燃烧的隐喻——C3 编译器正在将 VB6 源码"燃烧"成原生 x64 机器码，释放出沉睡已久的力量。

## 宣发叙事（可用作文案素材）

C3 是第三代 VB6 编译器。第一代是 VB6 IDE 自带的 c2.exe，仅支持 x86；C3 是第三代，将 VB6 工程直接编译为原生 x64 Windows 程序，支持 Unicode、多线程、COM 互操作，静态链接运行时零依赖部署。

在深邃的技术星空下，C3 横空出世。那个熟悉的 VB6 代码，正在被重新点燃。
