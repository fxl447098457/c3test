## 三、RTL 拆分必备：管线同步清单

S1~S3 属 RTL，每个新增/重命名/删除的 `.c` `.h` 都必须同步以下位置，漏一处就是构建失败或运行期找不到文件。

| # | 位置 | 要改什么 | `.c` | `.h` |
| - | ---- | -------- | ---- | ---- |
| 1 | `src/driver/c3rtl.rc` | `RCDATA` 资源项（现有 100-109），新增 ID | 必改 | 必改 |
| 2 | `src/driver/rtl_embedded.hpp` | `RtlResourceID` 枚举 | 必改 | 必改 |
| 3 | `src/driver/rtl_embedded.cpp` | `files[]` 表（约 95-104 行），解包用 | 必改 | 必改 |
| 4 | `src/driver/driver.cpp` | `msvcOpts.sourceFiles`（约 2156-2165 行） | 必改 | 不用 |

`driver.cpp` 里 sourceFiles 是**条件添加**的，拆分后要逐个照搬条件：

| 现有条目 | 添加条件 |
| -------- | -------- |
| `vb6rtl.c` / `vb6com.c` / `vb6_di_stubs.c` / `vb6_di_win32_stubs.c` | 总是添加 |
| `vb6forms.c` | `isGui` 或 `isDll` 为真时 |
| `vb6comserver.c` | `isDll` |

**跨文件可见性硬约束**：RTL 各 `.c` 是**独立编译单元**（都进 `sourceFiles`，由 MSVC 分别编译成 `.obj` 再链接），因此文件级 `static` 函数/变量**跨文件不可见**。拆分时：

1. 只被同族使用的 `static` → 随族一起搬走，保持 `static`。
2. 被多个族使用的 `static` → 提升为外部链接，声明集中到新增的内部头 `<模块>_internal.h`（定义仍留在主 `.c`）。
