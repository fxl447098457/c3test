## 三、RTL 拆分必备：管线同步清单

RTL 侧每个新增/重命名/删除的 `.c` `.h` 都必须同步以下位置，漏一处就是构建失败或运行期找不到文件。
（`.h` 拆分同样适用：`vb6rtl.h` → 伞头 + 7 子头即按本表落地。）
**移动文件位置**（如 2026-09-17 的家族子目录重排）只需改第 1、5 处的路径；
第 2、3、4 处记的是**解包后的平铺文件名**，与源码树目录无关，不用动。

| # | 位置 | 要改什么 | `.c` | `.h` |
| - | ---- | -------- | ---- | ---- |
| 1 | `src/driver/c3rtl.rc` | `RCDATA` 资源项（现有 **100-140，41 项**），新增 ID；路径含家族子目录 | 必改 | 必改 |
| 2 | `src/driver/rtl_embedded.hpp` | `RtlResourceID` 枚举 | 必改 | 必改 |
| 3 | `src/driver/rtl_embedded.cpp` | `files[]` 表（约 95-104 行），解包用 | 必改 | 必改 |
| 4 | `src/driver/driver.cpp` | `msvcOpts.sourceFiles`（约 2156-2184 行） | 必改 | 不用 |
| 5 | `CMakeLists.txt` | `C3RTL_EMBEDDED_FILES`（`.rc` 的 `OBJECT_DEPENDS`，约 197-244 行；**已与 rc 对齐为 41 项**）—— 漏了会继续嵌入旧文件 | 必改 | 必改 |

`driver.cpp` 里 sourceFiles 是**条件添加**的，拆分后要逐个照搬条件：

| 现有条目 | 添加条件 |
| -------- | -------- |
| `vb6rtl.c` / `vb6com.c` / `vb6_di_stubs.c` / `vb6_di_win32_stubs.c` | 总是添加 |
| `vb6forms.c` | `isGui` 或 `isDll` 为真时 |
| `vb6comserver.c` | `isDll` |

**跨文件可见性硬约束**：RTL 各 `.c` 是**独立编译单元**（都进 `sourceFiles`，由 MSVC 分别编译成 `.obj` 再链接），因此文件级 `static` 函数/变量**跨文件不可见**。拆分时：

1. 只被同族使用的 `static` → 随族一起搬走，保持 `static`。
2. 被多个族使用的 `static` → 提升为外部链接，声明集中到新增的内部头 `<模块>_internal.h`（定义仍留在主 `.c`）。

>   把函数体切成数段放进 `builtin/*.inc`，在**函数体内** `#include`。
>   比「提升局部 lambda 为成员函数」更稳：lambda 与局部常量原样不动，零重构。
