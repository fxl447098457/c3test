# 文件系统三控件（Drive / Dir / File ListBox）

> VB 内置控件，无需引用部件

## 1. 概述
三个配套控件：驱动器列表（组合框样式）、目录列表（列表框样式）、文件列表（列表框样式）。联动后即可组成简易"文件浏览器"。

## 2. 核心属性与事件

| 控件 | 核心属性 | 核心事件 | 其他常用成员 |
|---|---|---|---|
| DriveListBox | `Drive`（当前驱动器，如 "C:\"） | `Change`（改变驱动器时） | 外观同 ComboBox；另有 Click、DragDrop 等通用事件 |
| DirListBox | `Path`（当前目录） | `Change`（双击/改变目录时） | List、ListIndex；另有 Click、DblClick 等通用事件 |
| FileListBox | `Path`、`Pattern`（如 "*.txt;*.doc"）、`FileName`（选中文件名）、`List / ListCount / ListIndex` | `PathChange`、`PatternChange`、`Click`、`DblClick` | 过滤属性：`Archive / Hidden / Normal / ReadOnly / System`（布尔值，决定显示哪些属性的文件） |

## 3. 联动与取完整路径示例

```vb
Private Sub Drive1_Change()
    On Error Resume Next ' 防止光驱无盘等无效驱动器报错
    Dir1.Path = Drive1.Drive
End Sub

Private Sub Dir1_Change()
    File1.Path = Dir1.Path
End Sub

Private Sub File1_DblClick()
    MsgBox GetFullPath()
End Sub

Private Function GetFullPath() As String
    If Right(File1.Path, 1) = "\" Then
        GetFullPath = File1.Path & File1.FileName
    Else
        GetFullPath = File1.Path & "\" & File1.FileName
    End If
End Function
```

> 提示：FileListBox 只反映"设置 Path 那一刻"的目录内容，不会自动刷新；需要时用 `File1.Refresh` 或重设 Path。
