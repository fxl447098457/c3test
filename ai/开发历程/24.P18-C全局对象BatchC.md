# P18-C 兼容性填平 Batch C：全局对象

**日期**: 2026-06-30
**阶段**: P18-C
**回归测试**: 74/74 零失败
**里程碑**: M17

## 一、目标

实现 VB6 全局对象体系：Clipboard、Screen、Printer、Forms 集合，以及 Option Compare Text/Binary 字符串比较模式。

## 二、完成项（6项）

### 1. Clipboard 对象
- **SetText**: OpenClipboard + SetClipboardData (CF_UNICODETEXT)，支持 Unicode 文本
- **GetText**: IsClipboardFormatAvailable + GetClipboardData，返回 BSTR
- **Clear**: EmptyClipboard，清空所有格式
- **GetFormat**: 检查 CF_UNICODETEXT(1)/CF_BITMAP(2)/CF_METAFILEPICT(3)/CF_DIB(8)/CF_ENHMETAFILE(14) 等
- **cgen 分发**: `clipboard.settext` → `vb6_Clipboard_SetText`（方法调用），`clipboard.gettext` → `vb6_Clipboard_GetText()`（属性读取）

### 2. Screen 对象
- **Width/Height**: `GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) × TwipsPerPixel`，返回 twips
- **MouseX/MouseY**: `GetCursorPos` + twips 转换
- **ActiveControl**: `GetFocus()` 返回当前焦点控件 HWND
- **ActiveForm**: `GetParent(GetFocus())` 递归查找顶层窗体
- **TwipsPerPixelX/Y**: `GetDeviceCaps(hdc, LOGPIXELSX/Y)`，通常 15 twips/pixel
- **cgen 分发**: `screen.width` → `vb6_Screen_Width()`，`screen.activecontrol` → `(int32_t)(intptr_t)vb6_Screen_ActiveControl()`

### 3. Printer 对象
- **Print**: `TextOutW(hdc, x, y, text, len)` + `GetTextExtentPoint32W` 推进 CurrentX
- **EndDoc**: `EndPage` + `EndDoc` + `DeleteDC`，释放打印机 DC
- **NewPage**: `EndPage` + `StartPage`，分页
- **Width/Height**: `GetDeviceCaps(PHYSICALWIDTH/PHYSICALHEIGHT) × TwipsPerPixel`
- **CurrentX/CurrentY**: 全局变量 g_printerCurrentX/Y，支持 get/set
- **EnsureDC**: 惰性初始化，首次 Print 时 `CreateDCW(L"WINSPOOL", NULL, NULL, NULL)` + `StartDocW` + `StartPage`
- **cgen 分发**:
  - 读取: `printer.currentx` → `vb6_Printer_CurrentX()`
  - 赋值: `printer.currentx = value` → `vb6_Printer_SetCurrentX((int32_t)(value))`

### 4. Forms 集合
- **Register/Unregister**: 窗体 WM_CREATE 时 `vb6_Forms_Register(hwnd)`，WM_DESTROY 时 `vb6_Forms_Unregister(hwnd)`
- **Count**: 返回已注册窗体数 `g_formCount`
- **Item**: 按索引返回 HWND（0-based）
- **存储**: 全局数组 `g_formHwnds[64]`，最多 64 个窗体
- **cgen 分发**: `forms.count` → `vb6_Forms_Count()`，`forms.item` → `vb6_Forms_Item`
- **cgen 集成**: WndProc 的 WM_CREATE/WM_DESTROY 分支自动插入 Register/Unregister 调用

### 5. Option Compare Text/Binary
- **全局变量**: `g_vb6_optionCompareText`（0=Binary 默认，1=Text）
- **vb6_StrCmp 函数**: Binary 模式用 `wcscmp`，Text 模式用 `_wcsicmp`
- **cgen OptionStmt**: `Option Compare Text` → `g_vb6_optionCompareText = 1;`，`Option Compare Binary` → `g_vb6_optionCompareText = 0;`
- **wcscmp 替换**: cgen.cpp 中 5 处 `wcscmp(` 替换为 `vb6_StrCmp(`
  - Select Case 字符串比较（2处）
  - 字符串等于/不等于（1处）
  - 字符串范围比较 Case "a" To "z"（1处）
  - 字符串 Is 比较（1处）

### 6. Bug 修复

#### 6.1 vb6forms.h 缺少 stdint.h
- **问题**: vb6forms.h 使用 `int32_t` 类型但仅包含 `<windows.h>`，编译报 C2061 语法错误
- **修复**: 在 `#include <windows.h>` 后添加 `#include <stdint.h>`

#### 6.2 vb6forms.h ·n 损坏
- **问题**: vb6forms.h 第 323 行多个声明挤在一行，换行符被替换为 U+00B7 + 'n'（中间点+n）
- **修复**: PowerShell 脚本扫描并替换所有 U+00B7+'n' 为 CRLF

#### 6.3 gdi32.lib 链接缺失
- **问题**: Printer 函数引用 GDI API（CreateDCW/TextOutW/StartDocW 等），但 Console/DLL 链接路径未包含 gdi32.lib，导致 LNK2019 未解析外部符号
- **修复**: msvc_driver.cpp 中 Console 和 DLL 链接路径添加 `gdi32.lib`（GUI 路径已有）

#### 6.4 vb6rtl.c 花括号修复
- **问题**: `vb6_AppActivate` 缺少闭合 `}`，`vb6_MidSet` 多余 `}`
- **修复**: 补齐/删除花括号

## 五、关键设计决策

### Printer 惰性初始化
Printer DC 在首次 Print 调用时创建（CreateDCW），而非程序启动时。这避免了无 Printer 使用的程序加载打印驱动开销。EndDoc 后 DC 释放，再次 Print 会重新初始化。

### Forms 集合注册时机
选择在 WM_CREATE/WM_DESTROY 中注册/注销，而非在 Show/Unload 中。原因：WM_CREATE 恰好是窗体创建后、Form_Load 前的时机，确保 Forms.Count 在 Form_Load 中已可用。

### Option Compare 实现
使用全局变量 + vb6_StrCmp 函数包装，而非修改所有字符串比较的代码生成。cgen 中仅需将 5 处 wcscmp 替换为 vb6_StrCmp，vb6_StrCmp 根据 g_vb6_optionCompareText 选择大小写敏感/不敏感比较。
