# P18-F: 控件子类化

**日期**: 2026-06-30
**阶段**: P18 兼容性继续填平 — Batch F
**状态**: 已完成
**回归测试**: 74/74 零失败

---

## 一、目标

实现控件子类化机制，支持以下VB6事件：
1. PictureBox/Frame/Label 的 GotFocus/LostFocus（STATIC/BUTTON类控件不通过WM_COMMAND发送焦点通知）
2. 所有控件的 MouseEnter/MouseLeave（TrackMouseEvent机制）
3. 所有控件的控件级鼠标事件（MouseDown/MouseUp/MouseMove）
4. 所有控件的控件级键盘事件（KeyPress/KeyDown/KeyUp）

## 二、技术方案

### 2.1 架构设计

采用 **RTL基础设施 + cgen代码生成** 混合架构：

- **RTL层**：提供通用子类化安裈/移除/查询API + TrackMouseEvent封装
- **cgen层**：为每个需要子类化的控件生成独立的subclass WndProc函数

### 2.2 RTL通用子类化API

新增4个函数（vb6forms.h/c）：

| API | 功能 |
|-----|------|
| `vb6_InstallControlSubclass(hwnd, proc)` | 安装子类化，保存原始WndProc到VB6_OrigProc属性 |
| `vb6_GetOriginalWndProc(hwnd)` | 获取原始WndProc（子类化Proc内CallWindowProc用） |
| `vb6_RemoveControlSubclass(hwnd)` | 移除子类化，恢复原始WndProc，清理MouseTracked属性 |
| `vb6_StartMouseTracking(hwnd)` | TrackMouseEvent(TME_LEAVE)封装 |

复用了已有的Image控件子类化的 `VB6_OrigProc` 属性模式（`SetPropW`/`GetPropW`）。

### 2.3 cgen子类化Proc生成

为每个需要子类化的控件生成 `vb6_ctrl_subproc_XXX` 函数，拦截以下Win32消息：

| Win32消息 | VB6事件 |
|-----------|---------|
| `WM_SETFOCUS` | `_GotFocus`（仅PictureBox/Frame/Label/Image） |
| `WM_KILLFOCUS` | `_LostFocus`（仅PictureBox/Frame/Label/Image） |
| `WM_MOUSEMOVE` + `TrackMouseEvent` | `_MouseEnter` |
| `WM_MOUSELEAVE` | `_MouseLeave` |
| `WM_L/R/MBUTTONDOWN` | `_MouseDown` |
| `WM_L/R/MBUTTONUP` | `_MouseUp` |
| `WM_MOUSEMOVE` | `_MouseMove` |
| `WM_CHAR` | `_KeyPress` |
| `WM_KEYDOWN` | `_KeyDown` |
| `WM_KEYUP` | `_KeyUp` |
| `WM_DESTROY` | 移除子类化 |

### 2.4 子类化安装时机

- **安装**：在 `createFn`（CreateControls）中，所有控件创建完成后、菜单构建前
- **移除**：在主WndProc的 `WM_DESTROY` 中，遍历所有已子类化控件调用 `vb6_RemoveControlSubclass`

### 2.5 条件子类化

仅当控件存在对应事件处理器时才安装子类化（按需优化），检测逻辑：

```
PictureBox/Frame/Label/Image + 有 _GotFocus/_LostFocus → 子类化
任何控件 + 有 _MouseEnter/_MouseLeave → 子类化
任何控件 + 有 _MouseDown/_MouseUp/_MouseMove → 子类化
任何控件 + 有 _KeyPress/_KeyDown/_KeyUp → 子类化
```

## 四、关键技术细节

### 4.1 MouseEnter/MouseLeave 机制

Windows不提供MouseEnter/MouseLeave原生消息，需要：
1. 首次收到 `WM_MOUSEMOVE` 时，设置 `VB6_MouseTracked` 属性 + 调用 `TrackMouseEvent(TME_LEAVE)`
2. 首次设置时触发 `_MouseEnter` 事件
3. 收到 `WM_MOUSELEAVE` 时，清除 `VB6_MouseTracked` 属性 + 触发 `_MouseLeave` 事件
4. 鼠标再次进入时，重新设置跟踪

### 4.2 控件级鼠标/键盘事件参数

与Form级事件参数格式一致：
- `MouseDown(button As Integer, shift As Integer, x As Single, y As Single)`
- `MouseMove(button As Integer, shift As Integer, x As Single, y As Single)`
- `KeyPress(keyascii As Integer)` — ByRef，可修改keyascii取消按键
- `KeyDown(keycode As Integer, shift As Integer)`
- `KeyUp(keycode As Integer, shift As Integer)`

### 4.3 子类化 Proc 结构

```
static LRESULT CALLBACK vb6_ctrl_subproc_XXX(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    // 事件拦截...
    if (msg == WM_DESTROY) { vb6_RemoveControlSubclass((void*)hwnd); }
    WNDPROC orig = (WNDPROC)vb6_GetOriginalWndProc((void*)hwnd);
    if (orig) return CallWindowProcW(orig, hwnd, msg, wp, lp);
    return DefWindowProcW(hwnd, msg, wp, lp);
}
```

## 五、已知限制

1. **控件数组子类化**：当前仅对数组第一个元素(hwnds[0])安装子类化，后续元素未处理
2. **Frame容器内的控件**：子类化安装未覆盖Frame子控件
3. **Validate事件**：仍需CausesValidation基础设施，未在本批次实现
4. **MouseHover**：WM_MOUSEHOVER事件未实现（VB6中极少使用）
5. **控件级DblClick**：WM_LBUTTONDBLCLK未在子类化Proc中拦截
