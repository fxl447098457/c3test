# P17.4 GoSub/Return覆盖完善

> 日期: 2026-06-30
> 阶段: P17 兼容性收尾
> 基线: 74/74回归零失败

## 1. 问题分析

基础GoSub/Return已可用(goto+整数栈+switch分发)，但3项关键缺口：
1. **OnGoSubStmt完全未实现** — AST节点+Parser已有，但cgen仅emit `/* TODO: OnGoSubStmt */`
2. **hasGoSubInStmts不检测OnGoSubStmt** — 导致使用On...GoSub的过程不声明gosub栈
3. **固定栈32无溢出/下溢保护** — GoSub嵌套超32层或Return多于GoSub时UB

## 2. 修复方案

### 2.1 OnGoSubStmt代码生成
`On x GoSub label1, label2, label3` 生成：
```c
vb6_gosub_stack[vb6_gosub_sp++] = <retId>;  // 压入返回地址
{
    int _gosub_idx = <x>;
    if (_gosub_idx >= 1 && _gosub_idx <= 3) {
        switch(_gosub_idx) {
            case 1: goto vb6_label_label1;
            case 2: goto vb6_label_label2;
            case 3: goto vb6_label_label3;
        }
    }
}
vb6_gosub_ret_<retId>:;  // Return后的着陆点
```
- 索引1-based，超出范围时不跳转(继续执行下一条语句)
- 与GoSubStmt共享同一个返回地址栈和switch分发机制

### 2.2 hasGoSubInStmts修复
在检测GoSubStmt的同时添加OnGoSubStmt检测，确保使用On...GoSub的过程声明gosub栈变量。

### 2.3 栈溢出/下溢保护
- **GoSub/OnGoSub压栈前**: `if (vb6_gosub_sp >= 32) { return; }`
- **Return弹栈前**: `if (vb6_gosub_sp <= 0) { return; }`
- 防止嵌套超32层或Return滥用导致UB

### 2.4 语义分析
- 添加OnGoSubStmt dispatch case到语义分析器
- 添加visit(OnGoSubStmt&) — 将所有标签加入gosubTargetLabels_供验证

## 4. 测试结果

- 构建: 零错误

## 5. 已知限制

- 栈大小仍为32(VB6规范无明确上限，32足够覆盖实际用例)
- On...GoToStmt同样未实现(AST+Parser已有，但OnGoTo更简单——无需返回地址栈)
- OnGoSubStmt的index表达式不做编译期求值优化(每次运行时计算)
