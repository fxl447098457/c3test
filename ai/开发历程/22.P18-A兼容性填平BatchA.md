# P18-A 兼容性填平 Batch A

## 1. 目标

继续填补70项兼容性缺口的第一批次（Batch A），共10项：
1. Format$ 格式串支持（替换空操作）
2. MsgBox Win32 对话框（替换 console stub）
3. Mid$ 语句赋值（Mid$(var,start,len) = expr）
4. On...GoTo 代码生成
5. CCur/CDec/RGB/QBColor/FileDateTime/FileLen RTL
6. SendKeys/AppActivate RTL

## 2. 技术方案

### 2.1 Format$ 格式串
- 替换 `(void)fmt` 空操作，实现完整的格式字符串解析
- 日期格式：yyyy-mm-dd, yyyy/mm/dd, mm/dd/yyyy, dd/mm/yyyy, long date, short date, long time, short time, hh:mm:ss
- 数值格式：General Number, Currency (locale), Fixed, Standard, Percent, Scientific, Yes/No, True/False, On/Off, 0, 0.00, #,##0, #,##0.00
- 自定义数字模式：统计 `.` 后数字个数用于 `swprintf %.*f`
- 日期序列转换：FILETIME→SYSTEMTIME 使用 1899-12-30 epoch

### 2.2 MsgBox Win32 对话框
- 替换 console `wprintf` stub，实现 `MessageBoxW()` 调用
- 返回值映射：IDOK→1, IDCANCEL→2, IDABORT→3, IDRETRY→4, IDIGNORE→5, IDYES→6, IDNO→7

### 2.3 Mid$ 语句赋值
- 新增 `MidStmt` AST 节点（ASTNodeKind::MidStmt）
- Parser：`parseMidStmt()` 解析 Mid$(var, start[, length]) = expr
  - 当 Mid 后跟 ( 或 $ 时触发
  - 解析完括号后检查 = ：有则返回 MidStmt，无则回退为 CallStmt
- CodeGen：`CCodeGen::visit(MidStmt&)` 生成 `vb6_MidSet(&var, start, len, expr)`
- RTL：`vb6_MidSet(BSTR*, start, len, replacement)` — 1-based 替换，不改变字符串长度
- AST 基础设施更新：ast_visitor.hpp/c/pp, ast.cpp kindToString, ast_printer.cpp

### 2.4 On...GoTo 代码生成
- `CCodeGen::visit(OnGoToStmt&)` 实现 computed goto
- 与 OnGoSub 不同：无需 GoSub 栈操作，直接 evaluate index + 1-based switch → goto label
- Semantic：`visit(OnGoToStmt&)` 将 labels 加入 gosubTargetLabels_ 验证集合

### 2.5 新增 RTL 函数
- `vb6_CCur(double)→int64_t`：Currency = value × 10000
- `vb6_CDec(vb6_VARIANT)→BSTR`：简化为 CStr 字符串表示
- `vb6_RGB(r,g,b)→int32_t`：OLE color r|(g<<8)|(b<<16)，clamp 0-255
- `vb6_QBColor(n)→int32_t`：16色查找表
- `vb6_FileDateTime(BSTR)→double`：GetFileAttributesExW + FILETIME→VB6 date serial
- `vb6_FileLen(BSTR)→int32_t`：GetFileAttributesExW + nFileSizeLow/High
- `vb6_SendKeys(BSTR,int)→void`：SendInput KEYEVENTF_UNICODE per character
- `vb6_AppActivate(BSTR,int)→void`：FindWindowW + SetForegroundWindow

## 4. 验证

## 5. 遗留问题

- CDec 仅返回字符串表示，未实现真正的 Decimal 12字节类型
- SendKeys 不处理特殊键（{ENTER}, {TAB} 等），仅逐字符发送 Unicode
- AppActivate 不处理进程ID参数，仅按窗口标题查找
- FileDateTime/FileLen 不支持宽字符路径的长路径前缀
