日期: 2026-07-08

关联: 61-P24-08-StdErrorDesc-Expand-170.md

## 背景

Phase4 将 vb6_StdErrorDesc 从 60 扩展到 170+ 条目，但存在两个问题：
1. **错误号映射不准确**：735/744/746 被错误替换为 485/486/487（两者都是合法VB6错误号）
2. **条目来源混乱**：部分条目是从 DLL STRINGTABLE ID 直接映射，未与微软官方文档交叉验证

## 编译警告修复

### C4010: 单行注释包含行继续符
- 文件: vb6rtl.h:740
- 原因: 注释行末尾 `\` 被解释为行继续符
- 修复: 删除行末 `\`

### C5286: VARENUM→vb6_vartype 隐式转换
- 文件: vb6rtl.c:296/300/304/308/312/3437
- 原因: `v.vt = VT_I4` 等赋值，VT_I4 是 VARENUM 枚举，v.vt 是 vb6_vartype 枚举
- 修复: 添加显式 cast `v.vt = (vb6_vartype)VT_I4`

### C4142: 类型良性重定义
- 文件: vb6rtl.h:484-485 vs vb6rtl.c:324/332
- 原因: 声明返回 `int32_t`，定义返回 `long`（x64 上等价但类型不同）
- 修复: 统一声明为 `long vb6_RGB(...)` 和 `long vb6_QBColor(...)`

### C4312: OLE_HANDLE→HANDLE 类型截断
- 文件: vb6forms.c:1834/1838/1847
- 原因: x64 编译时 OLE_HANDLE(UINT) 是 32 位，HANDLE 是 64 位
- 修复: 使用 `UINT_PTR` 做中间转换 `(HANDLE)(UINT_PTR)hOle`
