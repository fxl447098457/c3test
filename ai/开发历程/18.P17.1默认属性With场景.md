# P17.1 默认属性With场景

> 日期: 2026-06-30
> 阶段: P17 兼容性收尾
> 状态: 已完成
> 回归: 74/74 零失败

## 1. 目标

修复 With 块内默认属性解析和代码生成的多个问题，使 `With Text1 / .Text = "Hello" / Debug.Print .Text` 等常见 VB6 模式正确编译运行。

## 2. 问题分析

P17.1 涉及 6 个互相关联的问题：

| # | 问题 | 根因 | 影响 |
|---|------|------|------|
| 1 | parsePostfix Dot 分支无限循环 | `break` 不消费 `.` token，while(true) 重复进入 Dot case | C3.exe hang |
| 2 | WithStmt 仅存 void* 临时变量 | 丢失对象类型信息，WithMemberExpr 无法区分控件/COM/UDT | .Property 生成 void*.field 错误 |
| 3 | IdentifierExpr With块内触发默认属性 | `With Text1` 中 Text1 被解析为默认属性值而非 HWND 引用 | With 对象引用错误 |
| 4 | Debug.Print .Text BSTR 类型误判 | bstrFuncs 不含 vb6_GetControlText | 输出类型错误 |
| 5 | MeExpr frm 中生成 vb6_Me | 无 isFormModule_ 分支 | Unload Me 引用未声明标识符 |
| 6 | Unload 函数未映射 | builtinFuncs 无 unload 条目 | vb6_Unload 未定义 |

## 3. 解决方案

### 3.1 WithObjInfo 类型栈（cgen.hpp）

新增枚举和结构，平行于 withObjectVars_ 栈：

```cpp
enum class WithObjKind { Unknown, FormControl, WithEventsCtrl, COMObject, ClassInstance };
struct WithObjInfo {
    WithObjKind kind = WithObjKind::Unknown;
    FrmControlType ctrlType = FrmControlType::Unknown;
    std::string ctrlOrigName;  // 仅 WithEventsCtrl 使用
};
std::vector<WithObjInfo> withObjectInfoStack_;
bool suppressDefaultProp_ = false;
bool isFormModule_ = false;
```

### 3.2 WithStmt 类型检测（cgen.cpp）

在 `visit(WithStmt&)` 中遍历对象表达式，优先级：
1. WithEventsCtrl (knownWithEventsCtrlVars_)
2. FormControl (knownFormControls_)
3. COMObject (knownObjectVars_)
4. ClassInstance (knownClassVars_)
5. Unknown (fallback)

控件类型使用 HWND 临时变量，其他用 void*。

### 3.3 suppressDefaultProp_ 标志

在 With 块对象表达式求值前设置 `suppressDefaultProp_ = true`，IdentifierExpr 检测到此标志时返回 `vb6_hwnd_<Name>` 而非 `vb6_GetControlXxx(vb6_hwnd_<Name>)`。

### 3.4 WithMemberExpr 属性分发

按 withObjectInfoStack_.back() 的 kind 分发：
- **FormControl**: `getControlPropReadFn(ctrlType, member)(tempVar)`
- **WithEventsCtrl**: 同上但用 ctrlOrigName 作参数
- **COMObject**: 设置 isComMarker_ 让下游处理
- **ClassInstance**: 查找符号表生成 `cProcName(member)(tempVar)`
- **Unknown**: fallback 到 `tempVar.field`

### 3.5 parsePostfix 修复

`Debug.Print .Text` 在 With 上下文中：当 withDepth_>0 且当前表达式是 Debug.Print/Assert 时，`return expr` 停止消费后缀，让参数解析器处理 `.Text` 为 WithMemberExpr。

原 `break` 方案不消费 `.` token 导致无限循环。

### 3.6 MeExpr + Unload 修复

- MeExpr: 新增 `isFormModule_` 分支，通过 knownFormControlOriginalNames_ 查找原始窗体名生成 `vb6_hwnd_FormName`
- builtinFuncs: 新增 `unload → vb6_UnloadForm` 映射
