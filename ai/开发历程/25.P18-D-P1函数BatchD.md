## 一、目标

实现 VB6 常用 P1 优先级内置函数：Unicode 字符串函数、计时器、字符串转换、数组过滤、指针函数、字符串对齐、日期名称、格式化函数。

## 二、完成项（17项）

### 1. AscW / ChrW（Unicode 字符函数）
- **AscW(BSTR s)**: 返回首字符 Unicode 码点（int32_t）
- **ChrW(int32_t code)**: 返回码点对应字符（BSTR）
- 实现：与 Asc/Chr 相同（BSTR 已是 wchar_t*），但语义明确为 Unicode 版本

### 2. AscB / ChrB（字节级函数）
- **AscB(BSTR s)**: 返回首字符低字节值（int32_t）
- **ChrB(int32_t code)**: 返回单字节字符（BSTR）
- 实现：`s[0] & 0xFF` / `(wchar_t)(code & 0xFF)`

### 3. Timer
- **Timer()**: 返回午夜后秒数（double，含毫秒小数）
- 实现：`GetLocalTime` → `hour*3600 + minute*60 + second + ms/1000.0`
- cgen：加入 zeroArgBuiltinFuncs 集合（无括号调用）

### 4. StrConv
- **StrConv(BSTR text, int32_t conversion, int32_t localeID)**: 字符串转换
- 转换模式：
  - vbUpperCase(1): towupper 逐字符大写
  - vbLowerCase(2): towlower 逐字符小写
  - vbProperCase(3): 每个单词首字母大写
  - vbUnicode(64)/vbFromUnicode(128): no-op（BSTR 已是 Unicode）
- 依赖：`<wctype.h>` (towupper/towlower/iswspace)

### 5. Filter
- **Filter(SAFEARRAY* source, BSTR match, int32_t include, int32_t compare)**: 过滤字符串数组
- 逻辑：遍历源 SAFEARRAY，检测每个 BSTR 元素是否包含 match 子串
  - include=1: 保留匹配元素
  - include=0: 保留不匹配元素
- 实现：两遍扫描（先计数，再创建结果数组并复制）
- 依赖：`vb6_SafeArrayCreate1D` + `VB6_SA_AT` 宏（定义在 vb6rtl.h）

### 6. VarPtr / StrPtr / ObjPtr（指针函数）
- **VarPtr(var)**: 返回变量地址 — 特殊 cgen 处理
  - 生成 `(int32_t)(intptr_t)&(<arg>)` 而非函数调用
  - 在 IndexOrCallExpr visitor 中拦截 "varptr" 关键字
- **StrPtr(BSTR s)**: 返回字符串数据地址 — wrapper 函数
  - `(int32_t)(intptr_t)s`
- **ObjPtr(void* obj)**: 返回对象地址 — wrapper 函数
  - `(int32_t)(intptr_t)obj`

### 7. LSet / RSet（字符串对齐）
- **LSet(BSTR str, int32_t length)**: 左对齐，右侧空格填充
- **RSet(BSTR str, int32_t length)**: 右对齐，左侧空格填充
- 超长截断，分配固定长度 buffer + 空格填充 + memcpy

### 8. WeekdayName / MonthName
- **WeekdayName(weekday, abbreviate, firstDayOfWeek)**: 星期名称
  - 全名：Sunday/Monday/.../Saturday
  - 缩写：Sun/Mon/.../Sat
  - firstDayOfWeek 偏移计算
- **MonthName(month, abbreviate)**: 月份名称
  - 全名：January/.../December
  - 缩写：Jan/.../Dec

### 9. FormatCurrency / FormatNumber / FormatPercent
- **FormatCurrency(value, numDigits, ...)**: 货币格式
  - `swprintf` 格式化 + 货币符号前缀
- **FormatNumber(value, numDigits, ...)**: 数字格式
  - 支持 groupDigits 千位分隔符
- **FormatPercent(value, numDigits, ...)**: 百分比格式
  - value × 100 + "%" 后缀

## 四、关键设计决策

### VarPtr 特殊处理
VarPtr 需要返回变量的地址（`&`），而非变量的值。标准的 builtinFuncs 映射只能生成 `vb6_Func(arg)` 形式的调用，无法添加 `&` 前缀。因此在 IndexOrCallExpr visitor 中添加特殊拦截：当函数名为 "varptr" 时，直接生成 `(int32_t)(intptr_t)&(<arg>)`。

### StrPtr / ObjPtr 用 wrapper 函数
与 VarPtr 不同，StrPtr 和 ObjPtr 的参数已经是指针（BSTR 和 void*），直接传递指针值即可，无需取地址。因此用简单的 wrapper 函数实现。

### Filter 两遍扫描
第一遍计数匹配元素数量，第二遍创建结果数组并复制元素。这避免了动态数组的复杂性，同时保持了 SAFEARRAY 的一致性。

### StrConv 简化
vbWide/vbNarrow/vbKatakana/vbHiragana 等亚洲语言特定转换未实现（需要 LCMapString 和 locale 支持）。vbUnicode/vbFromUnicode 为 no-op，因为 BSTR 已是 Unicode。
