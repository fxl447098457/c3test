## 完成项

### P20-49: vb6_ChDrive() 空操作修复
- **问题**: vb6_ChDrive 忽略参数始终返回 -1 (VB6 True = 失败)
- **修复**: 调用 `_chdrive()` 切换驱动器，始终返回 0 (成功)
- **文件**: src/rtl/core/vb6rtl.c

### P20-44: Printer.Width/Height 单位修复
- **问题**: Printer.Width/Height 返回像素值，VB6 期望返回 twips
- **修复**: `pixels * 1440 / LOGPIXELSX(Y)` 转换，使用 int64_t 避免溢出
- **文件**: src/rtl/core/vb6rtl.c

### P20-50: WebBrowser GoBack/GoForward/Refresh
- **问题**: cgen 生成 `(void)0` 占位，无实际调用
- **修复**:
  - RTL: vb6_WebViewGoBack/GoForward(返回-1暂未实现)、vb6_WebViewRefresh(用ShellExecute重新打开URL)
  - cgen: 三个方法分别调用对应 RTL 函数
- **文件**: src/rtl/core/vb6forms.h, src/rtl/core/vb6forms.c, src/backend/cgen.cpp

### P20-51: WebView ExecuteScript
- **确认**: 已有空 stub 实现 (返回0)，无需修改
- **状态**: 已确认

### P20-37: DriveListBox/DirListBox/FileListBox 控件
- **问题**: 三种控件解析器能识别但 cgen 完全无实现
- **修复**:
  1. **Win32 类映射**: DriveListBox→COMBOBOX, DirListBox/FileListBox→LISTBOX
  2. **控件样式**: DriveListBox = CBS_DROPDOWNLIST|WS_BORDER, Dir/File = LBS_NOTIFY|WS_BORDER|LBS_SORT
  3. **RTL 函数** (14个):
     - DriveListBox: Drive(读/写)、Refresh(用GetLogicalDriveStringsW填充)
     - DirListBox: Path(读/写,用SetPropW存储路径)、Refresh(用FindFirstFileW填充目录)
     - FileListBox: Path(读/写)、Pattern(读/写)、FileName(读/写)、Refresh(用FindFirstFileW填充文件)
  4. **cgen 属性映射** (3函数×3控件):
     - getControlPropReadFn: Drive/Path/Pattern/FileName + ListCount/ListIndex/List + Visible/Enabled
     - getControlPropWriteFn: SetDrive/SetPath/SetPattern/SetFileName + SetListIndex/SetList + SetVisible/Enabled
     - getDefaultPropertyName: DriveListBox→"Drive", DirListBox→"Path", FileListBox→"FileName"
  5. **初始化**: 控件创建后调用 Refresh/SetPath 填充列表内容
- **文件**: src/project/frm_parser.cpp, src/rtl/core/vb6forms.h, src/rtl/core/vb6forms.c, src/backend/cgen.cpp
