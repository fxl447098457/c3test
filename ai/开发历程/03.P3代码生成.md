# 03. P3 C代码生成 + MSVC驱动

## 目标

实现VB6→C代码生成器和MSVC编译驱动，达成里程碑M4：`c3 hello.bas -o hello.exe` 编译出可执行文件并正确运行。

## 过程

### 3.1 CCodeGen 框架搭建

- 单文件实现 `cgen.hpp` + `cgen.cpp` (~1370行)
- `CodeEmitter` 类管理缩进和行输出
- `CCodeGen` 类继承 `ASTVisitor`，遍历AST生成C代码
- 输出 `.h` 头文件（类型声明+函数前向声明）和 `.c` 实现文件

### 3.2 类型映射

- VB6 Long → `int32_t`, Integer → `int16_t`, String → `BSTR`, Boolean → `int16_t`
- VB6 True = -1 (VB6真值), Boolean 零/非零语义
- VB6默认参数传递 ByRef → C 指针, ByVal → C 值
- `mapTypeRef()` 和 `defaultValue()` 函数

### 3.3 表达式代码生成

- Pratt遍历生成表达式，内建运算符映射：
  - And/Or/Not → `&`/`|`/`~`（位运算，非逻辑）
  - Xor → `^`, Mod → `%`, Eqv → `(~(a^b))`, Imp → `((~a)|b)`
  - Concat → `vb6_BSTR_Concat()`, Pow → `vb6_Pow()`, IntDiv → `vb6_IntDiv()`
  - Like → `vb6_Like()`
- 字符串字面量 `vb6_BSTR_FromStr(L"...")`，自动去引号

### 3.4 语句代码生成

- 赋值语句带类型Cast
- If/For/Do/While/Select Case 控制流
- Select Case 用 if-else if 链 + 临时变量 `_vb6_select_N`
- Debug.Print 特殊处理：单参数→`vb6_Debug_Print()`，多参数→BSTR拼接+vb6_Str()类型转换

### 3.5 过程代码生成

- Sub → `void vb6_ProcName(params)`
- Function → 返回值用 `vb6_ret_ProcName` 局部变量 + `return`
- 用户过程名映射：`CalculateSum` → `vb6_CalculateSum`

### 3.6 模块代码生成

- 生成 `.h`（guard + includes + 前向声明）和 `.c`（函数实现）
- 自动生成 `main()` 入口点：`vb6_Init() → vb6_Main() → vb6_Exit()`
- 仅当存在 `Public Sub Main()` 时生成入口点

### 3.7 最小RTL实现

- `vb6rtl.h` (~225行) + `vb6rtl.c` (~374行)
- BSTR：`vb6_BSTR_Empty/FromStr/Free/Concat/Len`
- VARIANT：联合体 + 构造/转换函数
- 内置函数：Len/Left/Right/Mid/InStr/UCase/LCase/Trim/Chr/Asc/Val/Str/Format/MsgBox
- 数值函数：Abs/Sgn/Sqr/Round/Rnd
- 转换函数：CInt/CLng/CDbl/CStr
- Debug.Print：`vb6_Debug_Print/PrintInt/PrintDouble/PrintStr`
- 运行时生命周期：`vb6_Init/vb6_Exit/vb6_End`

### 3.8 MSVC驱动

- `msvc_driver.hpp` + `msvc_driver.cpp` (114行)
- 检测 vcvarsall 环境变量 → 调用 `cl.exe`
- 编译参数：`/std:c11 /DUNICODE /D_UNICODE /utf-8 /W3`
- RTL路径查找：编译器相对路径 + `VB6RTL_DIR` 环境变量
- Driver 集成：`runLinker()` 调用 MSVC 驱动

## 问题与修复

| 问题 | 根因 | 修复方案 |
|------|------|---------|
| 赋值右值为 null | Lexer `scanNumber()` 未解析字面量值 | 修改4个scan函数设置 intValue/longValue/doubleValue |
| Debug.Print "Count: "; i 崩溃 | `vb6_BSTR_Concat(BSTR, int16_t)` 类型不匹配 | 多参数Debug.Print用 `vb6_Str((int32_t)x)` 包裹非BSTR参数 |
| vb6_DebugPrint LNK2005 重定义 | RTL函数名与用户 `Sub DebugPrint` 冲突 | RTL函数重命名为 `vb6_DebugOutputFmt` |
| Select Case _vb6_select_0 未声明 | 临时变量只创建未声明 | 添加 `int32_t tempVar = testVar;` 声明初始化 |
| C4819 编码警告 | cl.exe 默认用系统代码页(936) | MSVC驱动添加 `/utf-8` 标志 |
| cgen.cpp 重复代码 | 编辑残留 | 清理 CallStmt handler 中重复的 emit+return |

## 决策

1. **C后端而非LLVM** — 基于决策006，C代码生成+MSVC路线更简单、更可控
2. **BSTR简化实现** — 不做引用计数，用4字节长度前缀+wchar_t数据
3. **Select Case → if-else if** — VB6支持范围比较和Is运算符，switch无法直接表达
4. **Debug.Print → BSTR拼接** — 简化处理，将分号分隔参数统一转BSTR拼接输出
5. **vb6_Str仅包装int32_t** — 当前仅处理整数→字符串转换，Double等后续补充
