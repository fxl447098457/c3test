## 技术要点

1. **Choose(index, v1, v2, ...)** 生成嵌套三元表达式：`((idx)==1 ? (v1) : ((idx)==2 ? (v2) : ... NULL))`

2. **Switch(cond1, val1, cond2, val2, ...)** 生成嵌套三元表达式：`(((cond1)!=0) ? (val1) : (((cond2)!=0) ? (val2) : ... NULL))`

3. **金融函数**使用标准 VB6 公式：
   - **SLN**：直线折旧 `(cost - salvage) / life`
   - **SYD**：年数总和法折旧 `(cost - salvage) * (life - per + 1) * 2 / (life * (life + 1))`
   - **DDB**：双倍余额递减法，带迭代账面值计算
   - **FV/PV/Pmt**：年金公式
   - **IPmt/PPmt**：逐期利息/本金
   - **RATE**：牛顿法迭代，100 次上限
   - **NPV**：从 SafeArray 折现现金流

4. **Lock/Unlock** 使用 Windows `LockFileEx`/`UnlockFileEx`，通过 `_get_osfhandle` 将 `FILE*` 转为 `HANDLE`

5. **Reset** 是 VB6 语句（类似 Beep/DoEvents），实现为完整 TokenKind+AST+parser+cgen 链

6. **Reset** 调用 `vb6_CloseAll()` — 等同于无参数 Close

7. **Partition** 返回格式化范围字符串 `"  start:   end"`，10 字符宽度字段

8. **关键问题**：将 Lock/Unlock/Reset 作为 addBuiltinFunc 注册时，与 Counter.cls 中名为 Reset 的方法产生"重复声明"冲突。解决方案：Lock/Unlock/Reset 是 VB6 语句而非函数 — 从语义注册中移除，保留为语句级处理器（parser+cgen）

## 修复的Bug

- **Lock/Unlock visitor 空操作**：原先生成注释，现改为实际 `vb6_Lock`/`vb6_Unlock` 调用，带 `(int32_t)`+`(int64_t)` 类型转换
- **Reset 与 Counter.cls 冲突**：`addBuiltinFunc("Reset")` 注册与 test_class.vbp 中 Counter.cls 的 Reset 方法冲突 — 改为 TokenKind+AST 语句实现，不再通过 addBuiltinFunc 注册
- **PowerShell 字符串插值 Bug**：cgen.cpp builtin map 中 `"r`n"` 在第 1268 行产生多余的 'r' 字符 — 通过逐行替换修复
- **parser_stmt.cpp 插入位置错误**：Reset case 被插入到 Unlock 的 if 条件内部 — 提取并重新插入到正确位置
