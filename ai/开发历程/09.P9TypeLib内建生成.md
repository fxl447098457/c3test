## 目标

集成 Windows CreateTypeLib2 API，在 C3 内部直接生成 .tlb 文件，彻底消除对 MIDL 外部工具的依赖（4MB），使 ActiveX DLL 编译成为真正的单步操作。P9 完成后，C3 源码中删除所有 MIDL 相关代码，不留任何 MIDL 痕迹。

## 问题

1. **DISPID 全局计数**: 当前 dispidCounter 跨所有 coclass 全局递增。理想情况每个 dispinterface 独立从1开始。低优先级，不影响功能。
2. **Property Get/Let/Set 未合并**: 同名属性的不同方法(Put/Get)视为独立 dispinterface 方法，未合并为单条目。低优先级。
3. **RC 仍依赖 rc.exe**: 未来可用 UpdateResource API 直接生成 .res 文件，进一步减少外部依赖。rc.exe 比 midl.exe 更容易获取（Windows SDK 默认安装）。

## 决策

1. **CreateTypeLib2 而非 MIDL**: 消除 4MB 分发依赖，单 API 调用链替代外部进程
2. **ICreateTypeInfo 而非 ICreateTypeInfo2**: CreateTypeInfo 返回 ICreateTypeInfo**，直接使用足够
3. **保留 rc.exe**: UpdateResource API 虽能避免 rc.exe 依赖，但实现复杂度更高，rc.exe 是 Windows SDK 标准组件，优先级低
4. **Symbol::params 而非 comMethodSig**: 用户定义的类方法参数在 Symbol::params，comMethodSig 仅用于 COM 导入接口
