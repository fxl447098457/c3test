## 一、目标

实现 VB6 窗体控件事件体系中的核心缺失项：键盘/鼠标/焦点/查询卸载/双击/激活失活事件。

## 二、完成项（8/9）

### 1. Form_KeyDown vb6_shift 修复
- **问题**: `vb6_shift` 始终为 0，无法检测修饰键
- **方案**: 使用 `GetKeyState(VK_SHIFT/VK_CONTROL/VK_MENU) & 0x8000` 实时读取
- **映射**: Shift=1, Ctrl=2, Alt=4（与 VB6 一致）

### 2. Form_KeyUp（WM_KEYUP）
- **新增**: `case WM_KEYUP` 处理
- **参数**: `(KeyCode As Integer, Shift As Integer)`，与 KeyDown 对称
- **Shift 检测**: 同 KeyDown 使用 GetKeyState

### 3. Form_MouseDown/MouseUp/MouseMove
- **消息映射**:
  - `WM_LBUTTONDOWN/WM_RBUTTONDOWN/WM_MBUTTONDOWN` → MouseDown
  - `WM_LBUTTONUP/WM_RBUTTONUP/WM_MBUTTONUP` → MouseUp
  - `WM_MOUSEMOVE` → MouseMove
- **参数**: `(Button As Integer, Shift As Integer, X As Single, Y As Single)`
  - Button: 1=Left, 2=Right, 4=Middle
  - Shift: GetKeyState + wParam MK_SHIFT/MK_CONTROL
  - X/Y: `(float)(int16_t)LOWORD/HIWORD(lParam)`

### 4. Form_DblClick（WM_LBUTTONDBLCLK）
- **新增**: `case WM_LBUTTONDBLCLK` 处理
- **参数**: 无参数（VB6 Form_DblClick 无参数）

### 5. Form_Activate/Deactivate（WM_ACTIVATE）
- **新增**: `case WM_ACTIVATE` 处理
- **逻辑**: `LOWORD(wParam) != WA_INACTIVE` → Activate, `== WA_INACTIVE` → Deactivate
- **仅当事件处理器存在时生成**

### 6. Form_QueryUnload
- **位置**: WM_CLOSE handler 中，Form_Unload 之前
- **参数**: `(Cancel As Integer, UnloadMode As Integer)`
- **逻辑**: UnloadMode=0 (vbFormControlMenu)，若 Cancel!=0 则 return 0 阻止关闭
- **意义**: 允许 VB6 程序在关闭前执行确认逻辑

### 7. GotFocus/LostFocus（TextBox/ComboBox/ListBox）
- 通过 WM_COMMAND 通知码实现：
  - TextBox: EN_SETFOCUS=256 / EN_KILLFOCUS=512
  - ComboBox: CBN_SETFOCUS=1024 / CBN_KILLFOCUS=2048
  - ListBox: LBN_SETFOCUS=4 / LBN_KILLFOCUS=5

### 8. GotFocus/LostFocus（CommandButton/CheckBox/OptionButton）
- 通过 WM_COMMAND 通知码实现：
  - BN_SETFOCUS=6 / BN_KILLFOCUS=7（button class 通知码）

## 三、未实现项

### 9. Validate 事件（推迟）
- **原因**: 需要 CausesValidation 属性基础设施
- **复杂度**: Validate 在焦点转移前触发，需跟踪焦点链和 CausesValidation 属性
- **计划**: 推迟到后续批次

### PictureBox GotFocus/LostFocus（推迟）
- **原因**: PictureBox 是 STATIC 控件，WM_SETFOCUS/WM_KILLFOCUS 发送到控件自身而非父窗口
- **方案**: 需要控件子类化（SetWindowLongPtrA GWLP_WNDPROC）拦截焦点消息
- **计划**: 推迟到后续批次

### Label GotFocus/LostFocus（不实现）
- **原因**: VB6 中 Label 是无窗口控件，不支持 GotFocus/LostFocus 事件

## 五、WndProc 消息处理顺序

1. `WM_CREATE` → Form_Load
2. `WM_SIZE` → Form_Resize
3. `WM_COMMAND` → Click/Change/DblClick/Scroll/GotFocus/LostFocus（含按钮焦点）
4. `WM_CLOSE` → Form_QueryUnload（P18-B 新增）+ Form_Unload
5. `WM_DESTROY` → PostQuitMessage
6. `WM_HSCROLL/WM_VSCROLL` → ScrollBar 事件
7. `WM_TIMER` → Timer 事件
8. `WM_KEYDOWN` → Form_KeyDown（P18-B: 修复 vb6_shift）
9. `WM_CHAR` → Form_KeyPress
10. `WM_KEYUP` → Form_KeyUp（P18-B 新增）
11. `WM_L/R/MBUTTONDOWN` → Form_MouseDown（P18-B 新增）
12. `WM_L/R/MBUTTONUP` → Form_MouseUp（P18-B 新增）
13. `WM_MOUSEMOVE` → Form_MouseMove（P18-B 新增）
14. `WM_LBUTTONDBLCLK` → Form_DblClick（P18-B 新增）
15. `WM_ACTIVATE` → Form_Activate/Deactivate（P18-B 新增）
16. `default` → DefWindowProc
