## 一、目标

补全 VB6 最常用的控件属性（使控件功能覆盖日常开发需求），并实现 COM 外部 DLL 的非固定属性/方法/事件动态调用。

两大部分：
1. **VB6 常用控件属性补全**：15 组属性/方法（P13.1-P13.15），从 Font 到 Default/Cancel
2. **COM 外部 DLL 动态调用**：6 项（P13.20-P13.25），从 TypeLib 事件源识别到综合验证

难点：COM 动态属性/方法依赖 IDispatch 后期绑定（已实现），但 COM 外部事件源（WithEvents 绑定外部 DLL 对象）需要 IConnectionPointContainer，此前完全缺失。

## 二、过程

### 第一部分：VB6 常用控件属性补全

#### P13.1 字体 6 属性（FontName/FontSize/FontBold/FontItalic/FontUnderline/FontStrikethrough）

**问题**：所有可见控件缺少字体相关属性，无法在运行时改变字体样式。

**实现**：
1. vb6forms.h/c 新增 12 个 RTL 函数（6 Get + 6 Set）：
   - FontName：`SendMessageW(hwnd, WM_GETFONT)` → `GetObject` → `lfFaceName`
   - FontSize：logFont → `lfHeight * 72 / dpi`
   - FontBold/Italic/Underline/Strikethrough：从 logFont 对应字段读取
   - Set 版本：修改 logFont → `DeleteObject` + `SendMessageW(WM_SETFONT)`
2. cgen.cpp 通用属性映射表新增 FontName/FontSize 等 6 个属性

#### P13.2 ForeColor/BackColor 前景/背景色

**问题**：7 种控件（Label/TextBox/CommandButton/CheckBox/OptionButton/Frame/Form）缺少颜色属性。

**实现**：
1. vb6forms.h/c 新增 `vb6_GetForeColor/vb6_SetForeColor`、`vb6_GetBackColor/vb6_SetBackColor`
2. ForeColor 通过 `GetWindowTextColor` / `SetTextColor`（GDI 绘制）
3. BackColor 通过 `GetClassLongPtr(hwnd, GCLP_HBRBACKGROUND)` / `DeleteObject` + `SetClassLongPtr`
4. OLE 颜色转换：`RGB(GetRValue(ole), GetGValue(ole), GetBValue(ole))`

#### P13.3 ListBox/ComboBox 列表操作

**问题**：ListBox/ComboBox 缺少 ListCount/List/ListIndex/AddItem/RemoveItem/Clear，列表控件不可操作。

**实现**：
1. RTL 新增 7 个函数：`vb6_GetListCount/vb6_GetListIndex/vb6_SetListIndex` + `vb6_AddItem/vb6_RemoveItem/vb6_ClearList` + `vb6_GetList`
2. Win32 API 映射：
   - ListCount → `SendMessage(LB_GETCOUNT/CB_GETCOUNT)`
   - ListIndex → `SendMessage(LB_GETCURSEL/CB_GETCURSEL)`
   - AddItem → `SendMessage(LB_ADDSTRING/CB_ADDSTRING)`
   - RemoveItem → `SendMessage(LB_DELETESTRING/CB_DELETESTRING)`
   - Clear → `SendMessage(LB_RESETCONTENT/CB_RESETCONTENT)`
3. cgen 方法调用特判：AddItem/RemoveItem/Clear/List 映射为函数调用而非属性读写

#### P13.4 TextBox 专用属性

**问题**：TextBox 缺少 MultiLine/ScrollBars/MaxLength/PasswordChar/Locked。

**实现**：
1. RTL 新增对应 Get/Set 函数
2. MultiLine → `GetWindowLong(GWL_STYLE)` 检查 ES_MULTILINE
3. ScrollBars → 窗口风格位 ES_AUTOHSCROLL/ES_AUTOVSCROLL/WS_VSCROLL/WS_HSCROLL
4. MaxLength → `SendMessage(EM_GETLIMITTEXT/EM_SETLIMITTEXT)`
5. PasswordChar → `SendMessage(EM_GETPASSWORDCHAR/EM_SETPASSWORDCHAR)`
6. Locked → `SendMessage(EM_SETREADONLY)` + 窗口风格 ES_READONLY

#### P13.5 Alignment 文本对齐

**问题**：Label/TextBox/CheckBox/OptionButton 缺少对齐属性。

**实现**：
1. RTL：通过 `GetWindowLong(GWL_STYLE)` 读取 SS_LEFT/SS_CENTER/SS_RIGHT
2. Set：修改风格位 → `SetWindowLong` + `InvalidateRect`

#### P13.6 TabIndex/TabStop Tab 键导航

**问题**：所有可聚焦控件缺少 Tab 导航属性。

**实现**：
1. TabStop → `GetWindowLong(GWL_STYLE)` 检查 WS_TABSTOP
2. TabIndex → Z-order 位置（`GetWindow(GW_HWNDPREV)` 计数）
3. Set：修改 WS_TABSTOP 风格位

#### P13.7-P13.15 其余控件属性（一次性提交）

**提交**：`b29121e` — P13.7-P13.15，+1534 行，涉及 cgen.cpp/vb6forms.h/vb6forms.c

**P13.7 MousePointer/MouseIcon**：
- 16 种光标类型（vbDefault/vbArrow/vbCrosshair 等）→ `LoadCursor(NULL, IDC_*)` 映射
- 自定义光标 → `LoadCursorFromFile` + `SetCursor`

**P13.10 BorderStyle**：
- TextBox: 0(None) = 移除 WS_BORDER，1(FixedSingle) = 添加 WS_BORDER
- Form: 0-5 对应 Win32 窗口风格（WS_CAPTION/WS_THICKFRAME/WS_SYSMENU 等）

**P13.11 HScrollBar/VScrollBar 核心属性**：
- Min/Max → `GetScrollRange/SetScrollRange`
- Value → `GetScrollPos/SetScrollPos`
- LargeChange/SmallChange → `SetScrollInfo` 的 nPage/nLine

**P13.12 Timer Interval/Enabled**：
- Interval → `SetTimer/KillTimer` + 计时器 ID 管理
- Enabled → 0=KillTimer, -1=SetTimer

**P13.13 Picture**：
- PictureBox → `STM_SETIMAGE` + `LoadImage/LoadPictureFromFile`
- AutoSize → `GetBitmapDimension` + 窗口 Resize
- Image 控件类似处理

**P13.14 SelStart/SelLength/SelText**：
- `SendMessage(EM_GETSEL/EM_SETSEL/EM_REPLACESEL)` 实现文本选择

**P13.15 Default/Cancel（CommandButton）**：
- Default → `SendMessage(DM_SETDEFID)` + BS_DEFPUSHBUTTON 风格
- Cancel → 运行时标志 + `DM_SETDEFID` 配合

### 第二部分：COM 外部 DLL 动态调用

#### P13.20 TypeLib 事件源接口识别

**提交**：`05acb05`

**问题**：COM 外部对象的 WithEvents 需要识别 TypeLib 中的事件源接口（`IMPLTYPEFLAG_FSOURCE`），此前 c3 的 TypeLib 解析器忽略此标志。

**实现**：
1. typelib_parser.cpp 激活 `IMPLTYPEFLAG_FSOURCE` 检测
2. ComCoClassInfo 新增 `defaultSourceIface` 指针 + `sourceIfaceNames` 列表
3. TypeLib 后处理阶段解析默认事件源接口

#### P13.21 IConnectionPointContainer/Advise 运行时

**问题**：COM 事件订阅需要 IConnectionPointContainer → IConnectionPoint::Advise 调用链，c3 完全缺失。

**实现**：
1. vb6com.h/c 新增 `vb6_ComAdvise/vb6_ComUnadvise`
2. 纯 C 兼容实现（不依赖 ocidl.h）：
   - 通过 vtable 偏移调用 IConnectionPointContainer::FindConnectionPoint
   - IConnectionPoint::Advise/Unadvise 通过 vtable 偏移调用
3. `+223 行 vb6com.c`

#### P13.22 外部 COM 对象 WithEvents 事件 Sink

**问题**：需要一个通用的 IDispatch 事件接收器，将 COM 事件 DISPDISPID 映射到 VB6 回调函数。

**实现**：
1. vb6com.c 新增 `vb6_CreateEventSink` — 通用 IDispatch 实现
2. Sink 对象：
   - `QueryInterface` — 返回 IID_IDispatch
   - `Invoke` — 根据 DISPID 查找注册的回调函数并调用
   - `AddRef/Release` — 引用计数管理
3. 回调注册：`sink->handlers[dispid] = vb6_com_evt_handler_ptr`

#### P13.23 外部 COM WithEvents cgen 集成

**提交**：`daa7069`

**问题**：编译器需要在 WithEvents 变量声明处生成事件 Sink 创建和 Advise 连接代码。

**实现**：
1. Symbol 新增 `comEventDispids`（事件 DISPID 列表）、`comSourceIfaceIid`、`comHasSourceIface`
2. Driver 从 TypeLib defaultSourceIface 填充事件信息
3. cgen 两种 WithEvents 模式：
   - **Class WithEvents**（内部类）：静态 Sink 结构
   - **ComClass WithEvents**（外部 COM）：`vb6_CreateEventSink` + `vb6_ComAdvise`
4. 生成 `vb6_com_evt_<var>_<evt>` 回调函数，桥接 COM 事件到 VB6 事件处理过程

**回归**：73/73 PASS

#### P13.24-P13.25 后期绑定验证 + Event Sink COM ABI 修复

| # | 问题 | 决策 | 原因 |

## 五、决策

- **属性实现策略**：每个属性一对 Get/Set RTL 函数 + cgen 属性映射表，保持架构一致性。
- **COM 事件架构**：通用 EventSink（IDispatch 实现），而非为每个 COM 对象生成专用 Sink，减少代码膨胀。
- **vtable 调用方式**：纯 C vtable 偏移（不引用 ocidl.h），保持 c3 RTL 的头文件独立性。
- **控件属性范围**：P13 只做运行时属性，设计时属性（如 Font 对话框）留给后续阶段。
