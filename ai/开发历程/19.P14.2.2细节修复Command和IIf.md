# P14.2.2 细节修复：Command语义注册 + IIf函数RTL

> 日期: 2026-06-30
> 阶段: P14 兼容性深化（遗留细节）
> 基线: 74/74回归零失败

## 1. 问题分析

P14.2.2（Dir/CurDir/Shell/Environ/Command文件系统5函数）在2026-06-29标记完成，但遗留两个细节问题：

### 1.1 Command语义注册缺口
- **Command$ 不支持**: VB6中`Command`和`Command$`等价（`$`后缀显式标注String返回），但parser只处理了`Input$`，没有`Command$`处理
- **Command$/CurDir/Dir/Environ 不在 bstrFuncs**: 3处`bstrFuncs`列表缺失这4个BSTR函数，导致`Debug.Print Command()`将BSTR强转为int32_t打印
- **CurDir 不在 builtinFuncs map**: 只有零参特殊处理（L2552），但builtinFuncs映射表缺入口
- **Dir 不在 builtinFuncs map**: 同上
- **CurDir 不在 zeroArgBuiltinFuncs**: `CurDir()`零参调用时不会生成括号

### 1.2 IIf函数RTL缺陷
- **C三元运算符短路求值**: `IIf(cond, a, b)`生成`cond ? a : b`，C三元只计算选中分支，但VB6 IIf**两个分支都求值**——语义不兼容
- **无类型分发**: 无论分支是String/Long/Double，都生成C三元，导致String IIf结果不被bstrFuncs识别，`Debug.Print IIf(cond,"a","b")`打印整数
- **无bool转换**: 条件表达式未做`!= 0`转换，VB6 True=-1在C中可能不正确
- **死代码**: `vb6_IIf()` RTL函数从未被调用，cgen完全绕过它

## 2. 修复方案

### 2.1 Command语义注册修复

| 修改 | 文件 | 说明 |
|------|------|------|
| Command$ parser | parser_expr.cpp | 添加`case TokenKind::Command`，消费可选`$`后缀，返回IdentifierExpr("Command") |
| command$ builtin | cgen.cpp | `{"command$", "vb6_Command"}` alias |
| curdir+dir builtin | cgen.cpp | `{"curdir", "vb6_CurDir"}` + `{"dir", "vb6_Dir"}` |
| curdir zeroArg | cgen.cpp | zeroArgBuiltinFuncs加入"curdir" |
| bstrFuncs x3 | cgen.cpp | 3处bstrFuncs列表加入`vb6_Command`/`vb6_CurDir`/`vb6_Environ`/`vb6_Dir` |

### 2.2 IIf函数RTL修复

**核心设计**: 将C三元运算符替换为**类型化RTL函数调用**。C函数调用语义天然保证所有参数在函数体执行前求值，完美匹配VB6 IIf语义。

| 类型 | RTL函数 | 签名 | 说明 |
|------|---------|------|------|
| String | `vb6_IIfBSTR` | `(int32_t cond, BSTR t, BSTR f) → BSTR` | 选中返回，未选中BSTR_Free释放 |
| Long | `vb6_IIfLong` | `(int32_t cond, int32_t t, int32_t f) → int32_t` | 简单选择 |
| Double | `vb6_IIfDouble` | `(int32_t cond, double t, double f) → double` | 简单选择 |
| Variant | `vb6_IIfVariant` | `(int32_t cond, VARIANT t, VARIANT f) → VARIANT` | VariantClear释放未选中 |

**类型推断策略**（cgen内联lambda `isBstrResult`）:
1. 任何一个分支是BSTR表达式 → `vb6_IIfBSTR`
2. 任何一个分支含小数点 → `vb6_IIfDouble`
3. 其他 → `vb6_IIfLong`

**bool转换**: 条件表达式显式加`!= 0`（`VB6 True = -1`，C需要`!= 0`）

## 5. 已知限制

- IIf混合类型分支（如`IIf(cond, "str", 42)`）未覆盖：当前类型推断BSTR优先，非BSTR分支会触发C类型不匹配
- IIf Variant返回值未拆箱：`vb6_IIfVariant`返回VARIANT，调用方需要根据目标类型拆箱
- Command$仅零参场景支持（`Command$(arg)`不存在于VB6规范，无需处理）
