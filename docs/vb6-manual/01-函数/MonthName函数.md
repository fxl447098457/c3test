# MonthName函数

       

**描述**

返回一个表示指定月份的字符串。

**语法**

**MonthName(***month*\[**,** *abbreviate*\]**)**

**MonthName**函数语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *month* | 必需的。月份的数值表示。例如一月是1，二月是2，等等。 |
| *abbreviate* | 可选的。**Boolean**值，表示月份名是否缩写。如果忽略，缺省值为**False**，表明月份名不能被缩写。 |
