# Join函数

       

**描述**

返回一个字符串，该字符串是通过连接某个数组中的多个子字符串而创建的。

**语法**

**Join(***list*\[, *delimiter*\]**)**

**Join**函数语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *list* | 必需的。包含被连接子字符串的一维数组。 |
| *delimiter* | 可选的。在返回字符串中用于分隔子字符串的字符。如果忽略该项，则使用空格(" ")来分隔子字符串。如果*delimiter*是零长度字符串("")，则列表中的所有项目都连接在一起，中间没有分隔符。 |
