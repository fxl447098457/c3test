# SLN 函数

返回一个 Double，在一期里指定一项资产的直线折旧。

**语法**

**SLN(*cost***, ***salvage***, ***life*)**

**SLN** 函数有下列命名参数：

|  |  |
|----|----|
| **部分** | **描述** |
| ***cost*** | 必要。**Double** 指定资产的初始成本。 |
| ***salvage*** | 必要。**Double** 指定资产在可用年限结束后的价值。 |
| ***life*** | 必要。**Double** 指定资产的可用年限。 |

  

**说明**

折旧期间必须用与 ***life*** 参数相同的单位表示。所有参数都必须是正数。
