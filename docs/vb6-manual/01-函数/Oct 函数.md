# Oct 函数

返回 **Variant** (**String**)，代表一数值的八进制值。

**语法**

**Oct**(*number*)

必要的 *number* 参数为任何有效的数值表达式或字符串表达式。

**说明**

如果 *number* 尚非整数，那么在执行前会先四舍五入成最接近的整数。

|  |  |
|----|----|
| **如果** *number* **为** | **Oct 返回** |
| Null | **Null** |
| Empty | 零 (0) |
| 任何其他的数字 | 最多可到 11 个八进制字符。 |

  

可以将适当范围的数前缀以 `&O` 来直接表示八进制数字。例如，八进制表示法的 `&O10 `代表十进制的 8。
