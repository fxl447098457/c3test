# Round函数

       

**描述**

返回一个数值，该数值是按照指定的小数位数进行四舍五入运算的结果。

**语法**

**Round(***expression* \[**,***numdecimalplaces*\]**)**

**Round**函数语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *expression* | 必需的。要进行四舍五入运算的数值表达式。 |
| *numdecimalplaces* | 可选的。数字值，表示进行四舍五入运算时，小数点右边应保留的位数。如果忽略，则**Round**函数返回整数。 |
