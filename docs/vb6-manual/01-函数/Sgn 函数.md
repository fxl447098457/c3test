# Sgn 函数

返回一个 **Variant** (**Integer**)，指出参数的正负号。

**语法**

**Sgn(***number***)**

必要的 *number* 参数是任何有效的数值表达式。

**返回值**

|                                                    |              |
|----------------------------------------------------|--------------|
| **如果** *number* **为** | **Sgn 返回** |
| 大于 0                                             | 1            |
| 等于 0                                             | 0            |
| 小于 0                                             | -1           |

  

**说明**

*number* 参数的符号决定了 **Sgn** 函数的返回值。
