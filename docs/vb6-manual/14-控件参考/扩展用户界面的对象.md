# 扩展用户界面的对象

这个组中的对象用来定制 Microsoft Visual Basic 用户界面。

这些对象可以完成以下任务：

- 在已有的命令栏中加入新的按钮或命令（在 Visual Basic 中，命令条是一个菜单或工具栏）。  
    
- 为自己的外接程序创建全新的菜单或工具栏。  
    
- 打开、关闭、移动用户界面窗口，以及改变它的大小。  
    
- 使用 CodePanes 集合或 CodePane 对象显示代码，并确定用户选定的代码。
