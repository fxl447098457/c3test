# Line 控件

               

**Line** 控件是图形控件，它显示水平线、垂直线或者对角线。

**语法**

**Line**

**说明**

在设计时，可以使用 **Line** 控件在窗体上绘制线。在运行时，除了使用 **Line** 方法外，还可以使用 **Line** 控件，或者使用后者代替前者。即使 **AutoRedraw** 属性设置为 **False**，**Line** 控件绘制的线也仍会保留在窗体上。可以在窗体、图片框和框架中显示 **Line** 控件。运行时不能使用 **Move** 方法移动 **Line** 控件，但是可以通过改变 **X1、X2、Y1** 和 **Y2** 属性来移动它或者调整它的大小。设置 **BorderStyle** 属性的效果取决于 **BorderWidth** 属性的设置。如果 **BorderWidth** 不是 1 而 **BorderStyle** 不是 0 或 6，则将 **BorderStyle** 设置成 1。
## 本项目的实现口径（ai/029 C29-1a）

`Line` 与 `Shape` 同族，是**有窗句柄的自绘控件**（自注册窗口类 `VB6_LINE`）；同样**没有任何事件**。

| 写法 | 读数 |
| --- | --- |
| `Line1.X1 / Y1 / X2 / Y2` | **容器缇值**（与 `.frm` 里存的是同一个口径），不是控件内部像素 |
| `Line1.Left / Top / Width / Height` | 这四个端点的**包围盒**；`Line` 自己没有独立的位置尺寸 |
| 赋任一端点 | 包围盒重算，**窗口跟着搬**（`Line1.X2 = 6000` 之后 `Line1.Width` 就是新的跨度） |
| `Line1.BorderStyle = 0` | 真的不画（透明）；旧实现把 0 钳成 1，那条死路已经修掉 |

本页"设置 `BorderStyle` 的效果取决于 `BorderWidth`"那条规则已实现：`BorderWidth` 非 1 且 `BorderStyle` 不是 0 或 6 时，`BorderStyle` 被强制回 1（实线）。

一条单位上的提醒：`BorderWidth` 是**像素**，其余几何属性是**缇**。水平线/垂直线在细的那一维至少给到笔宽，否则会被自己的窗口裁掉看不见。

判据：`tests\ctrlshape\`（CS1-CS4 几何落位、CS8-CS10 读写回路、CS11-CS14 端点搬窗口、CS15-CS16 那条强制规则）。
