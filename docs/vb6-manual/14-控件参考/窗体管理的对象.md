# 窗体管理的对象

该组中的对象用来在 Visual Basic 中控制和管理设计器。

使用这些对象，可以通过编程方式对窗体、控件、属性页或 ActiveX 文档等的设计者进行管理，可完成以下任务：

- 添加一个设计者。  
    
- 添加代码和控件。  
    
- 隐藏或显示设计者。  
    
- 定位控件。  
    
- 修改设计者的属性。
