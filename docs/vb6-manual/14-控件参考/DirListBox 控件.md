# DirListBox 控件

               

在运行时，**DirListBox** 控件显示目录和路径。这个控件可以显示分层的目录列表。例如，可以创建对话框，在所有可用目录中，从文件列表打开一个文件。

**语法**

**DirListBox**

**说明**

设置 **List**、**ListCount** 和 **ListIndex** 属性，就可以访问列表中的项目。如果需要显示 **DriveListBox** 和 **FileListBox** 控件，那么可以编写代码，使它们与 **DirListBox** 同步，并使它们之间彼此同步。
