# 事件响应的对象

这组对象用来对 Visual Basic 中发生的事件作出响应。VBA 对象可以是设计视图中的 Visual Basic 环境，或是处于运行状态的用户程序。

下列集合上也会有事件发生：

- VBProjects  
    
- VBComponents  
    
- VBControls  
    
- References

使用这些对象，可以监控、拦截和处理在 Visual Basic 界面中发生的事件，例如在工程中添加一个窗体，或添加一个工程。
