# 工程管理的对象

这个组中的对象用于 Visual Basic 中的工程控制和管理。

使用这些对象可以完成以下任务：

- 从几个工程中选择一个进行操作，或选择多个工程进行工程组操作。  
    
- 删除 Visual Basic 中所有其它的工程，并开始一个新工程。  
    
- 在当前的 Visual Basic 会话中添加一个新的工程。  
    
- 当某特定的工程被加载或卸载时，发出通知或以某种的形式作出响应。  
    
- 在其它地方显示工程名，例如在一个组合框中。  
    
- 修改工程选项。  
    
- 添加或删除组件。
