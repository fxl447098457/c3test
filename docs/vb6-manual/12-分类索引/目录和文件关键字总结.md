# 目录和文件关键字总结

| **作用**                     | **关键字**                            |
| 改变目录或文件夹。           | ChDir               |
| 改变磁盘。                   | ChDrive           |
| 复制文件。                   | FileCopy         |
| 新建目录或文件夹。           | MkDir               |
| 删除目录或文件夹。           | RmDir               |
| 重新命名文件、目录或文件夹。 | Name                 |
| 返回当前路径。               | CurDir             |
| 返回文件的日期、时间。       | FileDateTime |
| 返回文件、目录及标签属性。   | GetAttr           |
| 返回文件长度。               | FileLen           |
| 返回文件名或磁盘标签。       | Dir                   |
| 设置有关文件属性的信息。     | SetAttr           |
