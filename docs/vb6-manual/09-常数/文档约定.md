# 文档约定

Visual Basic 文档均遵循以下编排约定：

|  |  |
|----|----|
| **特定** | **说明** |
| **Sub**, **If**, **ChDir**, **Print**, **True**, **Debug** | 首字母大写的粗体字表示语言专用的关键字。 |
| **Setup** | 操作命令以粗体字表示。 |
| *object*, *varname*, *arglist* | 斜体的小写字母表示您须提供的信息。 |
| ***pathname***, ***filenumber*** | 粗斜体的小写字母表示参数，在那儿，可利用其位置指定或命名参数语法。 |
| \[*expressionlist*\] | 用在语法中，括号中的项目代表可选的。 |
| {**While** \| **Until**} | 用在语法中，表示可从括号中的项目中选择一个。而且必须选择一个，除非所有项目外层还有一个中括号，例如： |
|   | \[{**This** \| **OrThat**}\] |
| ESC,ENTER | 小的大写字母代表按键名称和按键顺序。 |
| ALT+F1, CTRL+R | 以加号 (+) 连接按键名称代表组合键，例如，ALT+F1 表示按下 ALT 键，再按下 F1。 |
