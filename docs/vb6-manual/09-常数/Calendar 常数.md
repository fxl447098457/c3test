# Calendar 常数

**Calendar 常数**

   

可在代码中的任何地方用下列常数代替实际值：

|                |        |                          |
|----------------|--------|--------------------------|
| **常数**       | **值** | **描述**                 |
| **vbCalGreg**  | **0**  | 指出使用的是阳历。       |
| **vbCalHijri** | **1**  | 指出使用的是伊斯兰历法。 |
