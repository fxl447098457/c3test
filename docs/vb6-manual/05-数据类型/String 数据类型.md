# String 数据类型

字符串有两种：变长与定长的字符串。

- 变长字符串最多可包含大约 20 亿 ( 2^31)个字符。  
    
- 定长字符串可包含 1 到大约 64K ( 2^16 ) 个字符。

**注意** Public 定长字符串不能在类模块中使用。

String 之字符码的范围是 0 到 255。字符集的前 128 个字符（0 到 127）对应于标准的 U.S. 键盘上的字符与符号。这前 128 个字符与 ASCII 字符集中所定义的相同。后 128 个字符（128 到 255）则代表特殊字符，例如国际字符，重音符号，货币符号及分数。**String** 的类型声明字符为美元号 (**\$**)。

## 多行字符串（本项目扩展）

> **本项目扩展**，非微软 VB6 原生语法：真 VB6 里反引号不是任何记号的开头，下面这种写法在
> VB6 里必然报错。设计取舍与验收读数见仓库内 `ai/028`、`ai/022`（批次 V1）。

```vb
Dim sql As String
sql = `SELECT Id, Name
FROM Users
WHERE Name = '张三' AND Tag = "vip"`
```

| 事项 | 口径 |
| :-- | :-- |
| 定界 | 起始反引号到下一个**未成对**的反引号；中间可以跨任意多个换行 |
| 双引号 | **原样**写，不需要像 VB6 那样双写 |
| 反引号本身 | 双写两枚表示一枚字面反引号（与 VB6 双写引号表示一枚引号同一个心智） |
| 枚数对照 | 空串 = 相邻两枚（起始 + 闭合）；一枚字面反引号 = 四枚（起始 + 双写 + 闭合）；三枚 = 未闭合 |
| 转义 | **完全没有**：反斜杠 n 就是两个字符；行尾的反斜杠、下划线、百分号都是普通文本 |
| 行内换行 | 一律读成 **CRLF**（`vbNewLine`，两格）。源文件存成 CRLF 还是 LF 都得到同一个字符串 |
| 起始换行 | 紧跟起始反引号的那**一个**换行不进入值（块状写法少一个空行）；第二个换行是内容 |
| 串内以 # 开头的行 | 是文本，不会被条件编译吃掉 |

**能出现在哪里**：任何字符串字面量的位置，包括 `Const` 的值、`Declare … Lib` 的库名、
`CreateObject` 的 ProgID、模块头的 `Attribute X = …`。理由：它在**词法出口**就折成与手写
`"…"` 完全同形的记号，编译器的语义层、后端、以及所有读字面量的地方看到的东西一字不变
（`ai/028` 的 R4 就是钉这一条）。

**不受影响的部分**：普通的 `"…"` 字符串一字不动 —— 不跨行、不插值、不新增转义，未闭合仍报
`VB1002`。反引号串未闭合报 `VB1007`。

**回归用例**：`tests\test_rawstr.bas`（18 条读数逐字比掉"与手写的 VB6 串相等"）、
`tests\rawstr_var\`（同一内容存成 GBK / UTF-8 BOM × CRLF / LF 四份，读数必须相同）、
`tests\rawstr_proj\`（`Attribute` 与工程内 `CreateObject` 两个落点）、
`tests\rawstr_neg\`（三条 `VB1007` + 一条 `VB1002`）。
