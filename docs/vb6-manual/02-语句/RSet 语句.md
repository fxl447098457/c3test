# RSet 语句

在一字符串变量中将一字符串往右对齐。

**语法**

**RSet** *stringvar* **=** *string*

**RSet** 语句的语法有下面这些部分：

|  |  |
|----|----|
| **部分** | **说明** |
| *stringvar* | 必要参数。为字符串变量名。 |
| *String* | 必要参数。在 *stringvar* 内想往右对齐的字符串表达式。 |

  

**说明**

如果 *stringvar* 比 *string* 长，**Rset** 会将 *stringvar* 中空余的字符以空白代替，直至字符串开头。

**注意** **RSet** 不能用于用户定义类型。
