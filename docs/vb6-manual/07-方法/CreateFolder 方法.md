# CreateFolder 方法

           

**描述**

创建一个文件夹。

**语法**

*object*.**CreateFolder(***foldername***)**

**CreateFolder** 方法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *object* | 必需的。始终是一个 **FileSystemObject** 的名字。 |
| *foldername* | 必需的。字符串表达式，它标识创建的文件夹。 |

  

**说明**

如果指定的文件夹已经存在，则发生一个错误。
