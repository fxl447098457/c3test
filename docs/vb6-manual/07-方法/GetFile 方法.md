# GetFile 方法

           

**描述**

返回一个和指定路径中文件相对应的 **File** 对象。.

**语法**

*object*.**GetFile(***filespec***)**

**GetFile** 方法语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *object* | 必需的。始终是一个 **FileSystemObject**. 的名字。 |
| *filespec* | 必需的。*Filespec* 是到一个指定文件的路径（绝对的或相对的）。 |

  

**说明**

如果指定的文件不存在，则发生一个错误。
