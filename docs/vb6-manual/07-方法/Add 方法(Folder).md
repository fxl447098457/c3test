# Add 方法(Folder)

           

**描述**

添加一个新的 **Folder** 到 **Folders** 集合。

**语法**

*object*.**AddFolders** *folderName*

**AddFolders** 方法的语法有如下几部分：

|                                       |                                     |
|---------------------------------------|-------------------------------------|
| **部分**                              | **描述**                            |
| *Object*     | 必需的。一个**Folders**集合的名称。 |
| *FolderName* | 必需的。新添加的**Folder**的名称。  |

  

**说明**

如果 *folderName* 已经存在，则产生一个错误。
