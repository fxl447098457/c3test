# WriteLine 方法

           

**描述**

写入一个指定的字符串和换行符到一个 **TextStream** 文件中。.

**语法**

*object*.**WriteLine(**\[*string*\]**)**

**WriteLine** 方法语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *object* | 必需的。始终是一个 **TextStream** 对象的名字。 |
| *string* | 可选的。要写入文件的正文。如果省略，一个换行符被写入文件中。 |
