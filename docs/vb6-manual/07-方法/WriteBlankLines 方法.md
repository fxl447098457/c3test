# WriteBlankLines 方法

           

**描述**

写入指定数量的换行符到一个 **TextStream** 文件中。

**语法**

*object*.**WriteBlankLines(***lines***)**

**WriteBlankLines** 方法语法有如下几部分：

|  |  |
|----|----|
| **部分** | **描述** |
| *object* | 必需的。始终是一个 **TextStream** 对象的名字。 |
| *lines* | 必需的。要写入的换行符数量。 |
