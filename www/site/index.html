核心优势

VB6 迈入新时代所需的一切

无需修改任何源代码，你的 VB6 工程直接产出原生 x64 Windows 程序。

x64 原生产出

生成 64 位 Windows 可执行文件和 DLL。突破 2GB 内存限制，原生支持 x64 COM 互操作。

Unicode 优先

BSTR 字符串全程 UTF-16。源文件支持 GBK/UTF-8/UTF-16 三种编码自动检测，中文处理零障碍。

多线程运行时

告别单线程单元模型。自由线程 COM、CreateThread、真正的并行执行，发挥多核性能。

安全编译保证

不支持的语法必然报错，绝不静默误编。误编比不编更危险——这是 C3 的核心信条。

静态链接 RTL

无运行时 DLL 依赖。200+ VB6 内置函数全部内置到可执行文件，部署干净利落。

COM / ActiveX DLL

原生 COM 客户端/服务端支持。编译 ActiveX DLL、TypeLib 导入、Implements 接口、WithEvents 事件。

架构对比

c2 → C3：三代的跨越

VB6 原生编译器 c2.exe 仅支持 x86。C3 带来三项根本性升级。

能力 c2.exe (VB6 原生) C3 (vb6c3)
目标架构 x86 (32位) x64 (64位) NEW
字符串编码 ANSI / Unicode Unicode (UTF-16) 全程 NEW
线程模型 单线程 / STA 多线程 NEW
运行时 MSVBVM60.dll 静态链接（零依赖部署）
调试支持 PDB PDB 原生调试信息
COM 支持 客户端 + 服务端 客户端 + 服务端 (x64)
ActiveX DLL 需 VB6 IDE 命令行直接编译 NEW
CLSID 固定 需二进制兼容（无法指定） 可在 VBP 中指定 NEW

当前支持范围与限制

C3 正在持续完善中，以下是目前已支持和尚未覆盖的控件及功能。

已支持的控件

  • Form / MDIForm窗体与 MDI 父窗体
  • CommandButton命令按钮
  • TextBox文本框
  • Label标签
  • CheckBox复选框
  • OptionButton单选按钮
  • ListBox列表框
  • ComboBox组合框
  • Frame分组框（BS_GROUPBOX）
  • PictureBox图片框（SS_BITMAP）
  • HScrollBar / VScrollBar水平/垂直滚动条
  • Image图像（SS_BITMAP）
  • Timer定时器（不可见，无窗口句柄）
  • Menu菜单系统（多级、分隔线、勾选、禁用）
  • WebBrowser浏览器宿主（WebView2 / ShellNavigate）

尚未支持的控件

  • Shape / Line图形与线条控件
  • Data / OLE数据绑定与 OLE 容器
  • DriveListBox / DirListBox / FileListBox文件系统控件
  • SSTab选项卡容器
  • Toolbar / StatusBar工具栏与状态栏（MSComctlLib）
  • CommonDialog通用对话框（MSComDlg）

其他限制

  • 控件数组之外的容器控件嵌套尚未完整支持
  • 不支持的语法必然报错，绝不静默误编
